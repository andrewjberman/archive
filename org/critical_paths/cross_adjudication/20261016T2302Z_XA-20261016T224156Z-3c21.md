(a) Host (1), account-return-daily, CONDITIONAL on ~F2's one read-only sizing read before any cell is cut; else (3) a new function; NEVER (2). Because: (1) is the 49 Financial shape (last stage of the function that writes the firm's returns day); (2) would give the served filled report a failure mode it does not have today. Conditions added: (i) any read grant to the Black Diamond transaction silver is scoped to Cottonwood's own key-prefix only (the cross-firm law; a bucket- or silver-wide read is refused), named by address() output; (ii) the stage runs AFTER the returns-day write is committed and its failure cannot alter or roll back account_return_daily (read back: a planted stage failure leaves that day's returns byte-equal); (iii) the 80 percent memory/time read uses the last scheduled fires' REPORT lines with the denominator of fires printed.
