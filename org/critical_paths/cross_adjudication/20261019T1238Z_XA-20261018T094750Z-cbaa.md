## Submission (verbatim)

## Context

AMGT_HARVST cj-2 and cj-6 make the shared `opal-gateway` resolve a slash key (`BP/_LN_Equity`, `NG/_LN_Equity`) to its one stored form.
The rule lives in `lib/research/identity/crosswalk.py` (`slash_safe_key`). The deployed gateway artifact ships only
`lib/trading_calendar.py` and `lib/opal_naming.py` from `lib/`, so the gateway carries a COPY of the rule in `app/harvest_keys.py`. The
only drift guard is arm 7 of `tests/test_cj2_slash_key_one_form.py`, which checks equality over 105 keys. This is row D1-W171-S3, ARMED.
The release cj-3 ships with the copy under signed pair halves. The row gates nothing else. It is CROSS-BOX because the gateway is shared
by every box.

## Position

Keep the copy, and put `test_cj2_slash_key_one_form.py` in EVERY gateway release's test list. cj-3 already does this. Revisit only if
the artifact starts shipping `lib/research/identity`.

## Why it gave pause

### Ambiguity

A copied rule can drift silently. If crosswalk changes and the gateway copy does not, the gateway reads a slash key from a form the
writers no longer use, which is the W170-S3 split again. The test catches drift only when it runs, and only over the 105 keys it holds.

### Out of pattern

The normal pattern is one rule, imported, never copied. Here the gateway artifact's packaging, which is site Z's host lane, decides what
can be imported. The only shipped `lib/` modules are the two named above, so importing crosswalk means changing what the artifact
ships. That is a cross-box packaging change on a host dell1 does not own.

### Other solutions

- **(b) Ship `lib/research/identity/` in the gateway artifact** and import the rule. This is better on drift, with one rule. It is worse
  on blast radius: it changes the artifact's packaging for every tool on a shared host, it is site Z's lane, and it pulls a module tree
  with its own imports into the gateway. That is a bigger release than the defect warrants.
- **(c) Serve the canonical key from the data, by writing a key-alias index** the gateway reads. This removes code duplication, but it
  adds a new stored artifact and a writer, which is more moving parts for two keys.
- **(a), the position, is the smallest change:** the copy is about 20 lines, guarded by an equality test that every release runs. Its
  failure mode is loud, a red test at release time, and never a silent wrong read in production.

## Ruling
