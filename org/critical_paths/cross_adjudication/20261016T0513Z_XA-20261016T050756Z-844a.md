## Why it gave pause

### Ambiguity

My bn-6 ruling asks for "the stop if the spend exceeds the stated figure". The code has no place to put a stop, so the ruling cannot be met
as written. Either the first fire is bounded some other way, or the stop is a person.

### Out of pattern

The normal pattern is a first fire over the whole population, with the stop read off the pair. That pattern assumes the program can stop
itself, and here it cannot.

### Other solutions

- **(b) The whole 171 names, with a human stop** (someone disables the task and reads the pool). No code, but someone must watch the fire.
  It spends about USD 119 before anyone reads a single figure. Worse.
- **(c) A spend cap built into the batch.** The strongest control, but it is new code and a new cell, and it outlives this one fire. Over-built
  for a first-fire question. It may be right later.
- **The capped tranche** makes the stop real at about USD 14 of exposure, for one day's delay. Better.
