## Review and Design Brief for Books Tab

### L2 (Advisor Book)

**Data Gaps Identified by DS:**
- **AUA Composition (NMNC/NMEC Breakdown):** Missing. Source: `client_performance.parquet`.
- **Geography and Account Type:** Missing. Source: `accounts_dimension_latest.parquet`.
- **Tax Exposure Summary:** Partial data available. Source: `client_tax_liability.parquet`.
- **Income/Fees and Portfolio Composition:** Missing. Sources: `client_performance.parquet` and `account_performance.parquet`.

**RD Layout Proposal:**
- **Summary Metrics:** Use `Panel`, `PanelContent`, and `DataTable`.
- **AUA Composition:** `DonutChart`.
- **Geography and Account Type:** `MapChart` or `BarChart`.
- **Tax Exposure Summary:** `PieChart`.
- **Income/Fees:** `DataTable`.
- **Portfolio Composition:** `StackedBarChart`.

### L3 (Relationship/Client View)

**Data Gaps Identified by DS:**
- **Performance Time Series:** Missing. Source: `client_performance.parquet`.
- **Full Account List:** Partial data available. Source: `account_performance.parquet`.
- **Deeper Client Segment Data:** Missing. Source: `client_dimension.parquet`.

**RD Layout Proposal:**
- **Client Overview:** `Panel` and `PanelContent`.
- **Performance Time Series:** `LineChart`.
- **Full Account List:** `DataTable`.
- **Client Segment Data:** `SegmentedControl`.

### L4 (Account + Holdings + Tax)

**Data Gaps Identified by DS:**
- **Detailed Holdings Information:** Lot-level detail from `holdings_lots.parquet`.
- **Tax Summary View:** Comprehensive tax exposure from `client_tax_liability.parquet`.
- **Account-Level AUA and Returns:** From `account_performance.parquet`.

**RD Layout Proposal:**
- **Account Details:** `Panel` and `PanelContent`.
- **Holdings:** `DataTable`.
- **Tax Intelligence:** `PieChart`.
- **Lot-Level Drill-Down:** `ExpandableTable`.

### TypeScript Interface Additions Needed
- **AdvisorBookData:** Add fields for NMNC/NMEC breakdown, geographic distribution, account type, tax exposure, income/fees, and portfolio composition.
- **ClientDetailPageData:** Add performance time series and deeper client segment data.
- **AccountDetailData:** Add detailed holdings and tax summary fields.

### API Endpoint Changes
- **New Endpoints:** May need to create new endpoints for fetching detailed holdings and tax data.
- **Query Key Changes:** Ensure endpoints support new fields required by the Books tab.

### Component Reuse and API Wiring
- **Component Reuse:** Confirm reuse of `Panel`, `PanelContent`, `DataTable`, and various chart components.
- **API Wiring:** Ensure all new data fields are correctly wired to the frontend components.
