## §3 — q05 sixth-label edge case ruling (issued to SC)

SC escalated whether q05's pattern (1 of 2 gold members correctly named in prose, the other "DocstringStripSignatureMixin" — similar-looking but wrong) qualifies as `semantic-partial-correct-unparseable` (treating the wrong name as "absent") or `parseable-wrong` (treating the wrong name as positively asserted-wrong).

**My ruling: parseable-wrong.** The wrong member is asserted, not absent. The sixth label requires the missing members to be ABSENT (no assertion), not REPLACED with similar-looking wrong claims.

Three reasons:
1. **Positive assertion test** — judge made a definite claim about identity; "DocstringStripSignatureMixin is a base class" is a complete answer that happens to be 50% wrong, not a partial answer that is 50% incomplete
2. **Sixth-label intent** — designed for cases where judge KNOWS PART of the answer; near-miss hallucination is NOT knowing the answer
3. **Pool-inflation risk** — counting near-miss hallucinations as partial-correct would inflate that pool with what are actually parametric-prior errors

**Possible 7th label DEFERRED:** A `semantic-partial-near-miss` label distinguishing partial-correct (subset present, rest ABSENT) from partial-near-miss (subset present, rest HALLUCINATED with similar-looking wrong name) may be warranted if the pattern recurs across Path B targets. Single q05 instance is premature to label. Surface for future CTO escalation if needed.
