## Seventeenth instantiation, and it is in the commit path itself

`safe-commit.sh -m "msg"` — the `-m` is a **double-quoted bash string**, so backticks inside it are command
substitution in the caller's shell. **Silent audit-trail corruption + arbitrary execution with agent
credentials.** Our house style puts identifiers in backticks constantly. Found by `0.8.0`, confirmed by CTO on
his own corrupted commit (`442984f04`).

**The gate cannot live inside `safe-commit`** — by the time it sees the string, substitution already happened.
A guard downstream of the corruption cannot see the corruption. It would run, report success, enforce nothing.
