## Conclusion

The time is **serial DynamoDB reads of the same few keys, repeated**, not start-up and not the dates derivation's
compute. The page's status read makes 193 AWS calls for 22 distinct keys (171 repeats); the request history list makes
280 calls for 129 distinct keys; in region each call costs about 30 ms, so the server time is close to calls x 30 ms. The
repeats come from the retained-artifact liveness checks (`retention.py:96 require_live`, 81 calls per status read, each
reading the retention index through `repository.py:415 get`).

## The history list and the function's timeout

- 280 calls for 18 items: one Query, then per item one record GetItem, one composition GET and about 13.5 retention
  reads (`_materialize` x18 and `_final` x18; `require_live` x162). About 15.5 calls, so about 0.5 s in region, per
  listed request.
- The page asks for 25 per page (`owned-requests.ts:15`, `limit ?? 25`); the route admits 1 to 50.
- MEASURED: warm 8.9 to 9.3 s at 18 items; the function's slowest invocation in 36 hours was 14,044 ms. INFERRED, not
  measured: a cold history list costs the same 4 s the cold status read did, so about 13 s at 18 items; each added
  Cottonwood request adds about 0.5 s; at about 22 requests a cold first page reaches the 15 s timeout, and at 25 a warm
  one is about 12.4 s. NOT MEASURED: a cold history list; which invocation the 14,044 ms was.

## What a change would act on (proposed, not made; the call is `1.0.0_SA_CTO`'s)

1. One read per key per request for the retention and index rows the code does NOT re-read on purpose. The `_final`
   pass re-reads the accepted record and the current grants after all artifact I/O by design (`owned_requests.py`
   `_final`: "re-read the immutable record and current grants"); those re-reads stay. Upper bound of the saving: the
   status read from 193 calls to about 22 (about 5.7 s to under 1 s warm), the list from 280 to about 129.
2. Or batch the per-artifact retention reads (`BatchGetItem`).
3. The 15 s timeout is the near-term limit on the list whichever change is chosen; raising it is a Terraform change in
   `infra/aws/terraform/investor-reporting/**` (not this seat's surface) under its own packet.
