the instances this composition emits carry those same registered types (deliberately — a new type

every query returns exactly what it should. **The defect is unreachable until the thing being tested

root-cause is better than either fix: **they** ruled instances must reuse registered node_types,
which made `node_type` non-discriminating — and both of us then wrote code treating it as if it still
discriminated. *One unpropagated consequence, two seats, neither visible to the other.*
