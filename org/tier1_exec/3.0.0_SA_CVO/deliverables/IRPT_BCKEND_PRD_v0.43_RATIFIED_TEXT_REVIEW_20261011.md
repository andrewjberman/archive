## The rule

The second witness gives no grade for a security on any day when, over the days of the grading run on which it has a bar, the bar
repeats the prior trading day's on more than half of them.

Like the two guard sentences, it can only remove grades. It answers the note on v0.42: for a security the first witness does not
carry, nothing dates the few days a mostly-repeated bar moves, so those days are now blank instead of served on the reader's word.
The cost figures in the addendum match the lines of the sizing record this seat printed (43.9218 and 43.9232 percent, 247 and 248).
Nothing was re-run.

## The three points the CTO asked to have attacked

1. **"More than half" is chosen.** For a rule that only removes grades, a chosen threshold is acceptable if the distribution is
   shown, and the addendum owes exactly that with the product form. It would not be acceptable for a rule that admits.
2. **Seven securities, not five, and two unsized.** Stated in the text. One of the two is carried by the first witness on most days,
   so it loses little; the other is unsized. Neither can add a served day.
3. **"The grading run" is not yet a fixed window.** This is the one that matters; see the note.

## The note: a day's grade must not depend on which run graded it

The rule is a property of a security over a window, and the window is not defined. Three consequences follow from the text as
written:

- the same security-day can be graded in a run over one window and not graded in a run over another;
- in a short window the share is unstable: over three days, two repeats exclude the security and one does not;
- so a day once served as own-date could later read blank, or the reverse, with no change in any price.

None of this serves a wrong figure: every outcome is either the grade v0.42 already admits or a blank. But a served claim that
changes with the length of the run is not reproducible, and a reader of two runs cannot tell a correction from a window effect.
The product form should fix the window (a stated number of trading days ending on the day graded, or the whole history held) and
say which. That belongs in the contract before the served change's pair, not after.
