Seven of eleven are **EXERCISED** and four are **APPLIED**. The split is deliberate:

- **APPLIED** where the outcome is a PROPERTY OF THE ARTIFACT that is true once built and cannot be
  faked by building it -- `FWD-2` (the vocabulary distinguishes instrument from world), `FWD-9` (one

  sharpest: an alert-delivery view that has never actually found a dead path is indistinguishable

  was commissioned over.

detector, quoted to him rather than derived here, and it sits in a `SOURCE` line and not in an

holds the same line: a number invented at L2 is a fabrication every later stage treats as ratified.

⛔ **NO TECHNICAL LANGUAGE IN ANY `ACCEPT`.** No serials, paths, table or key names, tool names, or
fabric jargon. Checked line by line: the ACCEPTs name people, things people see, and things people
would otherwise have to do instead. **The reason is structural, not stylistic** -- an ACCEPT written
in system vocabulary can only be graded by someone who knows the system, so it silently becomes a
check the builder grades.
