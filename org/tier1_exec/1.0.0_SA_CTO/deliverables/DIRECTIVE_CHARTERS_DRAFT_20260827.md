## The charter schema (five fields, each with one job)

| field | what it holds | what it is NOT |
|---|---|---|
| **PURPOSE** | one sentence: what the directive exists to produce | not a status |
| **SCOPE** | IN: the work classes it owns · OUT: the named neighbors it does not | not a member list |
| **DEVICE** | the fabric + the BASIS (whose word, when) | not inferred from members |
| **HEADLINER** | the `title:` a sprint line writes progress against | stable across sessions |
| **MEMBERSHIP CRITERION** | the predicate a project must satisfy to join | never a hand list |

Rule 24 record: axis = one directive's identity; the five fields are one grain (directive-level),
one intent each (EXCLUSIVITY held by the "what it is NOT" column); the domain is every live row;
STATE — PURPOSE/HEADLINER/CRITERION are stable-by-design, DEVICE moves only on Andrew's word,
SCOPE moves on his word or a ratified charter amendment. A charter edit is a law-class edit:
commit + broadcast + push state.
