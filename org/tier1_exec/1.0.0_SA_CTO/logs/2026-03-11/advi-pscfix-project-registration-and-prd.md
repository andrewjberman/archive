# ADVI_PSCFIX Project Registration and PRD — 1.0.0_SA_CTO

**Date:** 2026-03-11

## Objective

Register ADVI_PSCFIX and write the technical PRD for two correctness fixes to the
AUA view in Advisor Intelligence Assets Overview: (1) replace the rolling-12M
NMNC/NMEC classification with a static period-level definition, and (2) certify the
current-period total AUA against BD's official silver allocation parquet.

### 2. Key Decisions Made (Decisive — ADVI not live)

| Decision | Rationale |
|---|---|
| Do not replace positions cube (02) | Silver allocations are account-level, not security-level. Cannot produce `(account_id, asset_name, units)`. Original PSCFIX concept abandoned. |
| Restructure `timeseries_chart.json → aua` to pre-aggregated period series | Single daily series cannot encode static NMNC/NMEC for all three granularities simultaneously. Three series (quarterly/monthly/annually) is the only correct solution. |
| Drop rolling 12M from aua key entirely | Rolling produces incorrect static-view behavior. No v1 view needs rolling. Preserve as a code comment and future `aua_rolling` key when a concrete view needs it. |
| Silver certification scale applied to current period across all three series | One certification JSON per day, one scale factor, applied to the last entry of each granularity series. Uniform, auditable. |
| Non-blocking on missing silver allocation | If `05d` finds no silver file for today, no certification JSON is written. Publisher falls back to gold totals silently. Portal is unaffected. |
| Scale snapshots by same factor | `aua_by_architect.json`, `aua_by_state.json`, `aua_by_tax_status.json` all use the same scale so segment totals match the certified AUA. |

### 3. Epistemic Constraint Established

Two NMNC/NMEC definitions are formally separated. They must never share a rendering
path, JSON key, or chart component:

- **Static** (period-bound): v1 Assets Overview AUA toggle
- **Rolling/gradient** (trailing 12M): no v1 view assigned; reserved for future momentum analysis

This constraint is written into the PRD as non-negotiable.
