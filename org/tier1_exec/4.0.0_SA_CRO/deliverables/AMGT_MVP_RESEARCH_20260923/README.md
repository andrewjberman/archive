## Findings that change the schedule

1. **The analysis layer is the major unclosed product path.** The September 22 brief defines 13 outcomes, including a standard earnings report, continuation of the team's prior view, evidence per sentence, per-tab prose, synthesized Posture, immutable history and branded export. In the inspected source scopes there is no platinum analysis producer or corpus-substrate consumer beyond its tests; a complete paginated census of `opal-data-harvest` found **zero platinum objects**. Existing annual-filings analysis is useful implementation material, not proof of this new report.
2. **The corpus is real but partial.** This device currently has **93 name folders / 351 files**. The latest stored backlog resolves **33 folders and leaves 60 unresolved**. Stored report bytes, extracts and typed rows each number **123**, with 33 distinct securities in the typed table. Ten of eleven CORPUS orders are marked complete; the read-only-library proof remains pending. Induction-request generation does not perform identity induction.
3. **HARVST code completion has not reached its serving result.** All **18 orders** are complete. Gold mention/day/event outputs exist, but the deployed chatter writer lacks the new gold reader and its role lacks that gold prefix. The local default is still legacy. The latest daily gold table has **1,596 rows = six securities x 266 days**; dense rows do not prove successful collection from all five publishers. Timeline build and further publisher access retain specific recorded gates.
4. **RESAPP needs integration and operational closure.** Its **191 orders** comprise 181 complete, eight superseded, one withdrawn and one pending. A signed code-package comparison found **44 of 48 inspected Python members equal to local source; four differ**. Local header checks and the changed-held filing marker are absent from the deployed API. The `/refresh` route returns a declared carrier rather than enqueuing; its frontend client promises `{queued: boolean}`. Existing print/version routes operate on model blocks, not the new complete report revision.
5. **Collection is not continuously active simply because AWS is active.** The local publications, management and filings scheduled tasks are disabled. The cloud chatter schedule is enabled. That proves configuration, not a successful recent run or current upstream data. The latest stored universe is September 16; the latest crosswalk is September 22, and they have different populations.
