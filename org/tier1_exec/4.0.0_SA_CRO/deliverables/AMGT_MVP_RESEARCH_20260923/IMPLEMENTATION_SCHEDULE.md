# Consolidated AMGT implementation schedule

**Proposed September 23, 2026.** Start the clock when the program is activated with valid ownership, four implementers and independent review capacity. The schedule is dependency-based. The elapsed ranges below are planning allowances, not measured agent throughput or promised dates. External access/decision waiting is separate and can dominate elapsed time.

## Critical path

**Program ownership/interfaces -> accepted current source + corpus substrate -> gated per-part report -> deployed reader/page -> frozen export -> independent end-to-end review -> analyst acceptance and full backlog coverage.**

HARVST's gold cutover/timeline and CORPUS's proof/backlog replay run alongside security/report work. Any of them can block final MVP, but they should not prevent independent implementation on the others. The 60 unresolved library folders create a separate population-completion path that may outlast the first useful report.

## Release gates

**Gate A - existing system works through its real boundaries.** A permitted name reaches accepted filing/numeric data, the actual API and correct tabs; a real explicit refresh reaches the queue/consumer; failures remain visible. Measured package parity and effective narrow grants accompany the proof. All four Lead Panel products are evaluated, not two labels mapped to one source.

**Gate B - the new report is one reproducible artifact.** An authorized user opens a generated report with source-resolving machine prose, prior-view delta, sector-appropriate inputs and synthesized Posture. History and PDF reference that exact accepted revision. A changed input marks the right part stale; a failed/empty rerun preserves the prior good revision. A second consumer can read the same projection under its permissions.

**Gate C - complete coverage and business acceptance.** Every one of the current 93 library folders remains in the denominator; resolve/induct/report it or record an explicit approved exception. Publication history uses its own authorized security/publisher/day denominator. Every original RESAPP FWD-1..20, HARVST FWD-1..9, CORPUS FWD-1..9 and report O1..O13 has a result. A subset demo cannot close this gate. Retain actual analyst acceptance/forwarding evidence for the criterion requiring that human act.

Scope exclusions: voice-memo V2 Teams analyst, proactive flags and calendar/notifier sprint; new vendor subscriptions; unrelated portal/IRPT rewrites. Nothing already in the above FWD/O sets is silently removed by those exclusions.
