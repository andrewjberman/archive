## 5. Gaps and caveats

- **Most "production" dates are INFERRED.** They mark when a schedule first appears in Terraform code, which is the desired state, not proof it was applied. Live AWS was not read, and EventBridge does not expose rule creation dates.
- **The February 2026 Terraform dates understate first use.** That work imported Lambdas that already existed (e671d9c215). Lambda and EC2 "first add" dates are also only the dates code was captured into git (for example 6cff09c261, "code parity").
- **Many projects show "closed 2026-08-25".** That date is a registry sweep, not a completion date. Do not use it as a delivery date.
- **The script counts are proxies, not pipeline counts.** They include libraries and diagnostics, such as the E_ scripts. They also exclude code outside `data/*/scripts/{bronze,silver,gold}`, for example `data/find/*/scripts`, `data/canonical/schwab`, and the flat smartx and seeking-alpha scripts.
- **Directory moves shift the counts.** Inflection code sat under `data/orion` from 2026-04-22 to 2026-06-11, and Black Diamond moved into medallion layout on 2026-02-24 (9eac0a7849).
- **49 Financial's start date is a lower bound.** The relationship predates the repo: the Schwab data starts 2025-05-12.
- **Partner first-mention dates come from commit-message greps.** An earlier, unworded presence would be missed.
- **No date was found for a 49 Financial external-user go-live** and none is stated.
- **The ledger undercounts deploys before mid-June.** The deploy ledger only starts 2026-06-12, so June and earlier deploys are missing from it.
- **Personal data is omitted.** No Schwab master account numbers, user names or emails are included.
