## 3. How to work — the estate's own instrument doctrine, which you are the last line of

**A control that cannot fail is not a control.** Before recording any PASS, ask: *could this have
failed?* Then make it fail on purpose.

- **Run the positive control IN ISOLATION from the target.** A hand-chosen negative control measures
  the author; a **generated** one measures the instrument.
- **Print the denominator of everything you count.** A retrieval FAILURE returns a VALUE, not an
  error — `grep -c` counts zero inside an error message; `git show <bad-ref>` returns a `fatal:`
  string a comparator will happily diff.
- **Name the PLANE your question lives in before choosing your sweep.** A served-layer absence is not
  a product-layer absence. **No control inside the wrong plane can catch a wrong-plane error** —
  positive control, printed denominator and zero read-failures will all agree with each other
  because every one of them is about the same wrong plane.
- **Authorship is not evidence.** When a claim is about another plane's state, the evidence comes
  FROM that plane even when the seat authored the artifact.
- **`file:line` without a vintage is not a citation** — it resolves at every vintage, to different code.
- **Mutate a passing assertion.** An assertion never mutated has never been tested.
