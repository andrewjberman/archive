**This is the estate's shared-derivation law applied to agent verification** (2026-08-03:
*a tie is evidence only when the legs differ in DERIVATION*) -- blind re-derivation is the same
derivation twice; its agreement is one measurement wearing two signatures. The depth question
(a/b/c) was therefore the WRONG QUESTION and is DISSOLVED, not answered.

**The redesigned certification limb:**
1. Verifier input packet = the DEVELOPED STATE: full rectangle + domain bar + semantic layer
   (SYSTEM_DEFINITIONS + graph) + the target cell. Mission: attack the cell's COHERENCE.
2. Constraints codified in-schema, two tiers: MECHANICAL (validator-enforced, deterministic) and
   SEMANTIC (agent-assessed with the world model). Semantic findings that can be formalized
   migrate down to mechanical -- the validator permanently sharpens.
3. A verdict is VOID unless it names its discriminator (which constraint/cell/relation it checked).
4. Planted mutants must be COHERENCE-VIOLATING -- plausible in isolation, contradictory in
   context. A verifier that misses one was not assessing; the pass is void.
5. Re-derivation demotes to the narrow residue where it discriminates: transcription-risk cells +
   action-blocking cells (which get both checks).
