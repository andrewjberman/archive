## 1. THE KEY ENABLER, FOUND: the author's context profile is ALREADY MACHINE-EXTRACTABLE

An atom_decomp rectangle cites **instrument + locator + vintage per cell, by schema**. So the
author-context profile — what the author looked at, through what, at what vintage — is a
DETERMINISTIC PARSE of the artifact itself, not a self-report. **The complement (what the
validator should hold that the author did not) is therefore COMPUTABLE.** This is what makes the
whole design lean deterministic instead of judgment-shaped.

## 3. THE TOOL — `comp-adversary` (name = naming-act candidate): a THIN COMPOSER, rung-2 compliant

Input: the subject + the author artifact. Five stages, 1–3 fully deterministic, 4 deterministic
extraction, 5 derived:

1. **AUTHOR PROFILE** — parse the artifact's per-cell citations (rectangle schema) or the session's
   cited-evidence list → {sources, instruments, vintages, axes-run}.
2. **NEIGHBORHOOD** — comp-blast/trace (dependency) + comp-similar (functional) + comp-estate
   (thread) + comp-depth (grain) → the candidate context universe, denominator printed.
3. **COMPLEMENT** — neighborhood sources ∉ author profile · instruments with NO shares-substrate
   edge to the author's (comp-toolgraph) · axes not run (comp-axes snapshots) · warnings on the
   subject's nodes (comp-pulse diff) · record-drift rows (comp-state) · prior vintages
   (gitdrill/icedrill).
4. **PACKET** — comp-read digests of the complement sources (unread ledgers included) + the
   independent-instrument list WITH invocations + warnings + the axis checklist + the claim
   contract, role-marked per M-A ({ref, role: PRIOR_UNDER_TEST | SEMANTIC}).
5. **DELTA DECLARATION (automatic)** — the packet header enumerates exactly what the validator
   holds that the author did not, **derived, never self-reported** — which makes admissibility
   (§5) mechanically checkable.

**`--open` mode (his "leaving it open," made first-class):** emit ONLY the claim contract + an
isolation checklist — no estate context at all. The validator is the model's own priors.

**Every stage rides an existing tool; the new artifact is composition + the complement algebra.**

## 4. THE TWO-MODE DOCTRINE — constructed vs open are DIFFERENT CATCH CLASSES, not rivals

| Mode | Delta source | Catches | Cost | Cascade rung |
|---|---|---|---|---|
| **CONSTRUCTED** (default) | the computed complement | what the author's context MISSED — neighborhood, warnings, vintages, unrun axes | one composer run | deterministic/lexical (the construction) feeding an NLP/AI validator read |
| **OPEN** (`--open`) | the model's own priors vs the estate's | **estate-endemic groupthink** — conventions every seat internalized that are wrong from the outside | near-zero construction; isolation discipline only | model-prior (the AI rung, spent where it alone can see) |
| **SOVEREIGN** | business context no agent holds | "unnecessary," ownership, intent | his time | user input — ≤0.1%, highest signal |

Default = CONSTRUCTED. ADD OPEN on high-stakes or convention-heavy cells (both are cheap enough to
run together there). ESCALATE per the Cascade. Each pass declares WHICH mode and delta type it ran
— the empirical record then shows which delta types actually produce catches (the framework audits
itself, FRAMEWORK.md-style: the deltas are the product).

## 5. THE METHOD AMENDMENT (T11, steward's draft off tonight's exchange as specimen #1)

**Adversarial-admissibility rule:** an adversarial pass is admissible iff it carries a **declared
context-delta** (auto-derived where the composer ran; self-declared AND checkable otherwise). A
pass with no declarable delta is a RE-READ and is recorded as one — never counted as adversarial
coverage. Enforcement shape mirrors the plant: an inadmissible pass voids nothing downstream, it
simply does not count. Companion: the contested-cell step (case/counter-case before certification
where a cell admits rival readings), with the CRO×CVO four-options exchange as its first specimen.
