# STRUCTURE substitute-producer conformance predicate

A substitute producer conforms to `L2-adkg-4` only if, on the pinned STRUCTURE population of exactly 19,482 edge-incident, non-`semctl` nodes, it infers block membership with a **degree-corrected stochastic block model** using an explicitly versioned production implementation and a recorded model-selection objective, completes a declared **N=25** independent-run battery under the artifact’s anchor-derived seed policy, records for every run the seed, full partition assignment, objective value, iterations/convergence state, input digest and implementation version, and emits `W_STRUCTURE(i,j)` solely as the fraction of those 25 runs in which `i` and `j` share a block; it passes discrimination only when all 25 run records validate, the off-diagonal consensus has at least two distinct measured affinity values and is neither uniformly zero nor uniformly one, and an all-one constant-matrix mutant is refused. “Graph-tool-class” therefore describes this observable contract rather than a brand: it excludes a single-run or selected “best” partition, any non-degree-corrected fit, modularity/Louvain/label-propagation or other non-SBM community output relabeled as SBM, and an ad-hoc unversioned NumPy/SciPy experiment without the complete production/run/control record; any package or repository implementation meeting every predicate may conform. This follows the PRD’s definition of STRUCTURE as “graph topology + SBM consensus co-assignment,” its rule that every view must discriminate, its explicit statement that one SBM run is unreproducible and pair co-occurrence over N runs **is** the view, its measured warning that single runs disagree on roughly half the partition, and its classification of the existing hand-written NumPy/SciPy implementation as non-production engineering evidence (`docs/architecture/NFRA_C3MATERIALIZE_PRD.md:125-143,156-159,200-220,340-342 @ bb01a202721f9c3a719a3a662319cebc194a1720`).
