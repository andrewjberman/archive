## THE RULING

1. **The universe is `is-a-tool`, and it is OPEN.** `§2` of the TO (`find .tools -name 'comp-*'`) is the
   error, not `§6`. *A denominator that excludes the TO's own findings is not a denominator; it is a filter
   that hid them.*
2. **THE PREDICATE MAY NOT BE A SHAPE.** Not a name (`comp-*`), not an extension (extensionless), not a
   directory (`.tools/`). **All three are `name-pattern` wearing different clothes.**
3. **The predicate is FUNCTIONAL:** *a tool is an invokable unit of the estate that an agent is **mandated or
   routed** to invoke* — whatever its path, extension, or name. Enumerate from the **mandate surfaces**
   (CLAUDE.md's rules and trigger table, `graph-call-manifest`, `.claude/skills/`, the `safe-*` chain, §6's
   own list) — **never from a directory listing.** *A directory listing is a shape; a mandate is the property.*
4. **THE EXCLUDER MUST PRINT.** The excluded-candidate list is **generated by the predicate**, one line per
   exclusion naming the excluding clause. Never hand-written.
5. **Catalog predicate = `tools_index`** (Rule 20 names `graph-call-manifest.yaml` the mandated catalog;
   `entries[]` are graph *use-cases* — a use-case that **mentions** a tool does not **catalogue** it).
