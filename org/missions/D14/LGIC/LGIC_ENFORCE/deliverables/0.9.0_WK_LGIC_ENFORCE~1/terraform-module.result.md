## What landed

`infra/aws/terraform/modules/opal_name/` holds locals and outputs only. It has no resources, no providers and
no `external` data source.

- `generated_locals.tf` is written by
  `python lib/opal_naming.py generate --target infra/aws/terraform/modules/opal_name/generated_locals.tf`.
  - It is headed `GENERATED by lib/opal_naming.py from infra/logic/registry@50e4fabd1cb6a150`.
  - It carries these maps:
    - `scope_short`: long form to short form.
    - `scope_long`: every spelling `lookup()` resolves, to its long form.
    - `scope_class`
    - `name_scope_classes`
    - `scope_bucket`
    - `fence_patterns`: each firm's IAM ARN globs.
    - `account_id`
- `main.tf`: `output.name` is `format("%s%s-%s%s-%s", ...)` over those maps. It writes
  `{system}-{scope SHORT}-{function}[-{qualifier}]-{kind}`, and drops the scope slot when `scope` is null.
  - Two preconditions refuse:
    - a scope that is not the LONG form of a FIRM, GLOBAL or MASTER row, which `name()` also refuses;
    - a name missing its system, function or kind.
  - The maps are outputs too, so the fence cell can read `fence_patterns` without asking for a name.
- `variables.tf`: `system`, `scope`, `function`, `kind` and `qualifier`, all defaulting to null. Function, kind and
  qualifier must be kebab-case.
- `tests/vectors.json` is written by the same `generate` from `build_vectors()`, which is `name()`'s own output.
  It holds 32 vectors, byte-identical to a fresh regeneration and equal to the `vectors` verb's output.
- `tests/opal_name.tftest.hcl` has 37 run blocks, every one `command = plan`:
  - `coverage` refuses any vector count other than 32.
  - `vector_00`..`vector_31` each read their inputs and their expected name from `tests/vectors.json`. The file
    holds no expected name.
  - `refuses_short_scope`, `refuses_product_scope` and `refuses_partial_name` each expect `output.name` to fail.
  - `maps_without_a_name` checks that the maps are served when no name is asked for.
- `lib/opal_naming.py` (+10 lines, -2):
  - `_gen_locals` also renders `scope_class` and `name_scope_classes`.
  - `NAME_SCOPE_CLASSES` is one constant, now read by `name()`, `build_vectors()` and the locals, where each held
    its own copy of the tuple before. The locals therefore carry the list rather than a copy of it.
  - Behaviour is unchanged: the vectors are byte-identical, and `lib/tests/test_opal_naming.py` passes 75 of 75.
  - No change touches the CLI dispatch.
