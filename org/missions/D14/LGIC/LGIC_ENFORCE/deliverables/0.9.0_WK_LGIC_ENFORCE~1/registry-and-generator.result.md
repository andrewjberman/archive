  file validates with rc 0. The planted fixtures also draw 4 refusals of the real `scopes.json` vendor references, because a
  one-row systems file cannot satisfy them; this control shows the named defect alone is refused when the rest of the
  registry is real.

  those three. The unmutated copy reads 7 of 7 equal.

- **Commit-gate parts, run on the module alone:** py_compile rc 0, ds-precommit-check rc 0, ruff py39 clean, 0 non-ASCII
