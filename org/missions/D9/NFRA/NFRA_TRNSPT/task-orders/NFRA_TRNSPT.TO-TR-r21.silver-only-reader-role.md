`TR-r-21` (CTO ADDENDUM 12.1): FWD-5 wants a narrower reader -- an IAM role that reads Teams and outlook SILVER only, never bronze. The
transcripts root `infra/aws/terraform/transcripts/` already declares one reader role, the second named reader (`readers.tf`), which reads the
whole bucket. Its names come from `data/transcripts/scripts/teams/NAMES.json` `second_reader`, which is `lib/opal_naming.py` `name()` output.
Privacy is held by the KMS key (`main.tf` header and key policy): a principal with S3 read and no key grant gets AccessDenied.

**Build (plan-only; you apply nothing):**
1. `NAMES.json`: add `silver_reader` (role + policy) generated by `lib/opal_naming.py` `name('teams','global','transcripts-silver-reader',<kind>)`,
   with a `_provenance` line like `second_reader`'s. Run the builder; never type a name. A builder refusal -> the refusal clause.
2. `readers.tf`: `aws_iam_role.silver_reader`, `aws_iam_policy.silver_reader` and the attachment, names read from `NAMES.json`. The policy
   grants `s3:GetObject` on `teams/transcripts/silver/*` and `outlook/transcripts/silver/*` only, and `s3:ListBucket` on the bucket conditioned
   on `s3:prefix` to those two prefixes. Take the prefixes from the root's existing address usage; never write a bronze prefix.
3. TRUST: `variable "silver_reader_trust_principal_arns"`, a list with default `[]`. When it is empty, the trust policy is ONE statement that
   admits nobody: `Effect = "Deny"`, `Principal = { AWS = "*" }`, `Action = "sts:AssumeRole"`. When it is non-empty, it Allows exactly
   those ARNs. Andrew names the holder; the default stays empty.
4. `main.tf` key policy: one new statement `SilverReaderDecryptOnly` -- `kms:Decrypt` and `kms:DescribeKey` for the silver reader role's ARN,
   conditioned on `kms:ViaService` = S3 in us-east-1. The bucket key makes the context the bucket, so the prefix boundary is the role's S3 policy
   (step 2), never the key. Change no other statement.
5. `data/transcripts/scripts/tests/test_silver_reader_role.py` (new; parses the .tf text, no AWS, no terraform binary):
   `test_policy_reads_silver_only` (every s3 Resource or prefix of the silver policy is under a `/silver/` prefix);
   `test_no_bronze_prefix_granted` (no `bronze` anywhere in the silver role's policy or its ListBucket condition);
   `test_trust_admits_nobody_without_holder` (the variable defaults to `[]`, and with it empty the trust is the single Deny statement).

If a silver object carries held-out rows whose text is NOT wiped (read the Research silver writer `teams/research_fold.py` and
`teams/holdout.py`; do not read S3), file a surprise row (`NFRA_TRNSPT-D2-W2-S<k>`, next unused across every document under
