## 4. The ask: BLAST RADIUS, written for three halves, pinned to `a88661b145`
### Half 1 (CTO~Z) -- the code that runs
- **ONE new WRITE tool, `copy_site_file_to_s3(site_id, item_id, quarter)`.** It reads ONE SharePoint `.xlsx` item with the CALLER's own delegated Graph token and puts it to ONE key under the configured root: `<root>quarter=<q>/<sanitized name>.xlsx`. Classified `WRITE_REVERSIBLE`, `TOOL_WRITE_CLASS = write_files` (the class of `upload_text_to_site` and `save_email_attachment_to_site`), native undo = delete the written key, blast dimension `files:1`; it is NOT in SAFE_TOOLS (not read-only).
- **Refusals (all return `{error, refused: true}` and write nothing):** a quarter outside `20YYQn`, n in 1..4 (`2026Q9` is refused); an item name that is not `.xlsx`; a name with no usable stem; a non-plain Graph id; an item that is not a file; content that is not bytes, empty, over 50 MiB, or not a zip (`PK\x03\x04`) container; a root that is unset or not shaped `s3://<bucket>/.../bronze/fee_statement/`; an **existing key** (S3 `If-None-Match: *`: 412 -> refused, "no overwrite", also under a race). Any other S3 error is raised, not swallowed.
- **Both branches of a call:** (a) REFUSED -> `{error, refused}`, no `PutObject` succeeds, no key written; (b) ADMITTED -> exactly ONE new key under `quarter=<q>/`, response `{s3_key, bytes, sha256}`; **never an overwrite**.
- **Writers of the property "a key under `smartx/49financial/bronze/fee_statement/`" in the gateway:** before this release **N = 0** gateway tools; after **N = 1** (this tool). Writers of "the tool's class" (`destructive_ops.DESTRUCTIVE_OPS`, `TOOL_WRITE_CLASS`; `data_entitlement.NATIVE_TOOLS`): **N = 3** places, all three edited (a tool missing from any is fail-closed `UNCLASSIFIED`, which no tier is entitled to). Writers of the grant: **N = 1** (the one Terraform resource).
- **Who can call it:** the entitlement model is unchanged; a write tool of class `write_files` needs a tier/grant carrying `write_files` (master admin "*" and the `write_files` grants already given). No grant file, profile or entitlement row is written by this release.
