## THE SIX SYNTHETIC MUTATIONS (F20-AC5 / F20-AC6)

All six run in ONE harness, `__tests__/fe-s-13/content-pins.test.ts`, through the SAME
`checkConsumed()` function the live test uses. Each is applied to an in-memory deep copy of a
freshly-read snapshot. **Nothing writes to `docs/contracts/investor-reporting/v1/`** -- it is the
counterpart's artifact and is not in this grant in any direction. A fifth test re-reads the
contract from disk LAST and reports `CONTRACT ON DISK AFTER SIX MUTATIONS: 0 finding(s)`, which is
the control over the control: a mutation that had escaped onto disk would make both arms
meaningless.

| id | arm | mutation | expected | measured |
|---|---|---|---|---|
| A1 | ADDITIVE | a new OPTIONAL field on a consumed schema -- `ResolvedScope.experimental_scope_hint`, added to `properties` and deliberately NOT to `required` | GREEN | GREEN |
| A2 | ADDITIVE | a new ROUTE the client does not call -- `GET /api/scoped/investor-reporting/benchmarks/{seriesId}`, operation `benchmark-series` | GREEN | GREEN |
| A3 | ADDITIVE | a new ENUM MEMBER on a field the client does not branch on -- `PerformanceReport.lineage.provider += 'ADDEPAR'` | GREEN | GREEN |
| B1 | BREAKING | a REQUIRED FIELD the client reads is REMOVED -- `ResolvedScope.permitted_account_set_fingerprint`, out of both `properties` and `required` | RED on `fields` | RED on `fields` |
| B2 | BREAKING | an OPERATION the client calls is RENAMED -- `narrative-packet` -> `narrative-packet-v2`, route key left alone | RED on `operations` | RED on `operations` |
| B3 | BREAKING | a ROUTE KEY the client uses is DELETED -- `GET /export/{exportId}/download` -> `/export/{exportId}/file`, operation left behind | RED on `routeKeys` | RED on `routeKeys` |

```
ADDITIVE CHANGE TOLERATED: 3 of 3
BREAKING CHANGE CAUGHT: 3 of 3
```

**Each breaking arm is asserted on ITS OWN AXIS**, not merely on "something fired". A mutation
caught by the wrong axis is not evidence for the axis it was written to exercise, and B3 is
written so the operation survives on a different key precisely so the route-key check cannot be
passed by the operation check.

**A3's choice is not arbitrary.** `lineage.provider` is CARRIED by the adapter
(`producer: wire.lineage.provider`) and compared to nothing. The three enums this client DOES
branch on are `measurement_basis.fee_basis`, `.accrual_basis` and `.annualization`; none is
touched. "A field the client does not branch on" is therefore a read of the adapter, not an
assumption.
