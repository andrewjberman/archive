## What is NOT exercised

- **No live call of any kind.** No request was made to the deployed function, no vendor call, no write to any AWS resource. The vendor path of the function is behind `job.lambda_handler`'s per-use consent sentence, which the environment does not set.
- **The real injected objects** behind the four carried method sites (the retained `ReportRepository.validate`, the operation-fenced transport) are not in this package; the arms use fakes shaped like them.
- **PDF text extraction and certification** (PyMuPDF is not on the replay box: the replay reads `BackendUnavailable` from `foreign_firm_names` on both zips; whether the Lambda's layers carry it was not read): `foreign_firm_names` and `build_publication` are stand-ins in the publisher arm; tests that need a real PDF fail identically on both trees.
- **Real DynamoDB, S3 and SQS semantics** (conditional expressions beyond the in-memory fakes, KMS, versions, queue visibility): the arms use in-memory fakes.
- **The Lambda-side route reach of the history reader, the repository and retention service-subject paths, and the resident loop:** exercised through the repository's pin tests and fakes, not through a deployed route.
- **Any request from a real principal**, including the allow-listed Opal producer principal: `producer_for` is read with synthetic principals only.
- **The 409 binding-case runner** builds `entry.ENTRY`; the upload route exists only in `generate_installed.build_boundary` and is replayed by the route arm instead.
