## Part 2 -- the wiring (`reports/generate_installed.py`)

```python
        "read_classifications": comparison_catalogue.classifications_reader(clients["dynamodb"]),
```

with `import comparison_catalogue` beside the function's other lazy imports, and in `build_boundary` serve the
catalogue operation through a closure that passes the port:

```python
    def catalogue(request, scope, event, ctx):
        return generate_entry.read_comparison_catalogue(
            request, scope, event, ctx, read_classifications=ports["read_classifications"])
    ...
        operations={generate_entry.OPERATION: compute, UPLOAD_OPERATION: upload,
                    generate_entry.CATALOGUE_OPERATION: catalogue},
```
