- **Branch A (per name: the pre-write comparison holds, the object read back equals the build):** the in-memory moved fields are a subset of `{fund_form_ref, model_rows}` and the differing input kinds a subset of `{continuation, fund_form, model_block}` (before the write); the written object has `subject.security_key` the name, `method_version` `"amgt-corpus-dossier/15"`, `fields` equal to the pre-write build's for every field other than `model_rows` and `fund_form_ref` (these two are compared against the second build `write_one` makes: equal, or STOP), the recomputed `content_sha256` equal to the stored one, the object name `as_of=<as_of>.<_inputs_sha16(inputs)>.json`. - **Branch B (ANY difference: a moved field outside the set, an input kind outside the set, a read-back that differs, `put_performed` false, a name outside the list, a stored count that is not +1 for the name, the two builds of one name differing in a field other than `model_rows`):** STOP that batch; write nothing further; record the exact difference and the names written so far. **Before the write:** nothing is written for that name. **After the write:** a written object cannot be unwritten; its repair is a still NEWER dossier object from a corrected run (the gateway serves the newest), decided by the issuer and the CTO; no key is deleted by the seat.
