## Work Completed

### 1. fabric-commits.py — commit scraper (script 4, the enrichment layer)
`git log` -> `{code: [commits]}` + `{author: [commits]}`. Project-code match is longest-first-with-consume (ADHC_COMPIL_V4 beats ADHC_COMPIL) + multi-code aware (close(A + B)). CLI: `--project` / `--by-author` / `--days N` / `--json`. The shared dependency for scripts 1-3 (decoupled subprocess `--json`).

### 2. fabric-projects.py — HOT / COLD projects (scripts 1+2)
Reads `org/projects/*.json` (147), keeps not-closed (status not in complete/closed/cancelled/merged/superseded/done), computes last-activity = max(JSON mtime, latest commit for the code via fabric-commits), partitions HOT (<72h) / COLD (>=72h). Per project: status, owner (JSON field or dominant recent committer), last-activity age, commit count, latest commit, and a deterministic <=2-sentence status (first 2 sentences of current_phase + BLOCKING + latest-commit fallback). `--hot` / `--cold` / both / `--json`. Live: **14 hot, 5 cold** (the 5 cold = closure-debt, flagged to COO as a /drive sweep target).

### 3. fabric-check.py --agents — agent->project activity (script 3)
Each live agent (LIVE/ALIVE) mapped to its project + one-line what-it's-doing (from the broker summary). Project inference (deterministic, best-effort): exact code in summary -> distinctive code-token in summary (token unique to one code, len>=5, e.g. MDLP/GLDINC/DEMOAUTH) -> latest commit's code -> dominant commit code -> (unmapped). Folded into the full `fabric-check.py` run as a section + `--agents` mode.

### 4. DEAF detection + reaped-exclusion (LD-0158, mid-session)
COO surfaced a reachability regression from LD-0157 (retiring self-tick loops also removed the dead-Monitor re-arm -> idle ~A lanes go unreachable). Added a DEAF bucket: unread top-level inbox + telemetry-quiet (>600s) + recently-active (<2h). COO /drive catches -> MSTR respawns (no per-agent tick reintroduced). Tightened with a 2h recency bound (1 true positive vs 14 offline-with-mail false-pos). Folded COO's tuning: exclude intentionally-reaped serials (optional `org/mcp/reaped_serials.json`, 6h window). Re-elevated the Monitor-death root-cause to the infra broker/poller charter (operational impact now observed). CTO accepted.

## Decisions Made

| Decision | Rationale |
|----------|-----------|
| 4 scripts, 1 shared enrichment layer (fabric-commits) | Honors Andrew's "4 scripts" decomposition; fabric-commits is the DRY foundation feeding hot/cold + agent-mapping. |
| Last-activity = max(JSON mtime, latest commit) | Deterministic dual-signal; commit recency is primary "worked-on," JSON mtime the floor. |
| Distinctive-token inference for agent->project | Agents write short forms in summaries; exact-code-only missed them. Token unique-to-one-code keeps it deterministic while catching MDLP/GLDINC/DEMOAUTH. |
| DEAF 2h recency bound + reaped-exclusion | A DEAF "needs respawn" signal must mean recently-live-now-deaf, not long-offline-with-mail or intentionally-reaped. |
| Route kill-agent reaped-record to exec, not self-edit | kill-agent.ps1 is owned-paths ANY_EXEC_OR_AE (not MSTR); govern-through-the-org. |
| Best-effort project tag, authoritative one-line | The agent's summary one-line is the truth; the project tag is inferred context — documented as such. |
