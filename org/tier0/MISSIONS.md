## Why this file no longer holds content

This was the hand-written mission register. It is retired because it had become **the second record
of the same thing** — 49KB hand-kept here against a 25KB generated file at `org/missions/MISSIONS.md`
— and two records of one subject, with no gate between them, is the drift hazard this estate keeps
paying for. Keeping both would have guaranteed that one of them started lying.

**Nothing was lost.** Before retirement its content was migrated into the tree:

| what | where it lives now |
|---|---|
| per-sub-group stance, frontier, blocked-on, holes | `org/missions/{GROUP}/{SUB_GROUP}/state.yaml` |
| the 7 named objectives (O1/O2/O3 …) | same file, `objectives:` |
| the synthesized goals, Andrew-approved | same file, `goal:` · root at `org/missions/GOALS.yaml` |
| prose summaries | `org/missions/{GROUP}/{SUB_GROUP}/execsum.yaml` |
| the aggregate priority view | `org/missions/MISSIONS.md` — **compiled, not written** |
| commit attribution | `org/missions/{GROUP}/{SUB_GROUP}/commits.jsonl` |

## Where to go instead

- **Read state:** `org/missions/MISSIONS.md` — regenerated by `comp-missions compile`, ordered by
  activity intensity, and stale-labelled rather than silently aged.
- **Change state:** edit the relevant `state.yaml`. Never edit `MISSIONS.md`; it is a build artifact.
- **Taxonomy + attribution rules:** `org/tier0/missions.yaml`.
- **Decision record:** `org/tier0/ledger/LD-0341.md`.

A post-commit hook keeps the tree current, so this pointer should never need to be followed twice.
