# LD-0649 -- Portal pre-push: an accurate refusal message when a gate script is missing

## Decision
After a missing-gate ERROR on a trunk push (LD-0647), the hook also printed "a partner-facing adapter has an un-threaded output path",
which is false when the cause is a missing script. A new flag (`D1_GATE_FAILED`) is set only when the D-1 gate RAN and exited non-zero;
the sentence prints only then. No exit code changes.

## Provenance chain (Art. XIII)
MSTR~DELL2 (bus 85d63e5a, 01:47Z, "Cosmetic: ... which is untrue when the cause is a missing script") -> LD-0647's refusal text is
what an agent reads at a trunk refusal -> `/integrate`: an unowned path is repaired by the integrator's box -> this edit.

## Why now
The refusal has no in-hook escape (CTO msg 109028); its wording has to point at the real remedy, `bash .tools/portal-hooks/install.sh`.

## Assumptions
None beyond LD-0646 to LD-0648.

## Alternatives considered
Leave it: rejected, a wrong cause on a refusal sends the reader to the adapters instead of the install.

## Rollback plan
`git revert` of the commit that carries this entry; re-run `bash .tools/portal-hooks/install.sh` on each box.
