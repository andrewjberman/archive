# LD-0524 - /canonical-flow: pick up any in-flight or limbo project at the limb your role owns

**His word, verbatim and entire.** In `andrew_instruction_ref` above; the second sentence ("Don't overfit to one
case, it should be for any in limbo project") is the design constraint.

**Decision.** The skill is a reference to the spine plus three things the spine does not do: a measurement
procedure (the limb from artifacts, on both roots), a closed limbo taxonomy keyed to artifact grammar and
ownership, and a role-to-limb map with a four-step decide rule (hold -> stop; mine -> pick up; mine but the input
gap is another limb's -> hand back; not mine -> hand off). It is an execution entry point: after the report the
seat performs its limb's act through the normal gates. It never registers a new project, lifts a hold, cuts a
task order at a non-COO seat, or engages the CVO before L8.

**Provenance chain (Art. XIII).** andrew_instruction (verbatim) -> D0 Agent Infrastructure -> the skill file ->
the first run at the Tier-1 seat he names, on the project he names (acceptance on an observed run).

**Stakes.** S1: a process instrument; reversible by deleting the folder.

**Rollback plan.** Remove `.claude/skills/canonical-flow/`.

**Files or paths touched.** `.claude/skills/canonical-flow/SKILL.md`, `org/tier0/ledger/LD-0524.md`.
