# LD-0580 - Remove the bg-concierge-gate.sh hook

## His words

> "the BG concierge gate is bullshit pull that off right now."

## What changed

`.claude/settings.json`, `hooks.PreToolUse`: removed this entry (the third of four PreToolUse hooks
that fired on every Bash/PowerShell/Write/Edit/NotebookEdit call across the whole fabric, checking
identity and no-op'ing for every seat except one):

```json
{
  "matcher": "Bash|PowerShell|Write|Edit|NotebookEdit|mcp__bloomberg__.*|mcp__opal-gateway__.*|mcp__opal-gateway-bbg__.*",
  "hooks": [
    {
      "type": "command",
      "command": "bash \"$CLAUDE_PROJECT_DIR/.tools/hooks/bg-concierge-gate.sh\"",
      "timeout": 10
    }
  ]
}
```

The script `.tools/hooks/bg-concierge-gate.sh` (216 lines) is left on disk, untouched, unwired. Its
test suite (`.tools/hooks/tests/test_bg_concierge_gate.sh`) is also left in place. Restoring the fence
later, in whole or narrower, is one settings.json edit.

## What the removed gate was doing, named so it is not discovered later as a silent gap

Built 2026-08-07 (Andrew-direct, MSTR~Z terminal) for exactly one seat, `0.0.3_BG_BBGTerminal` (the
Bloomberg-Terminal Teams-concierge seat), and tightened once (F8, 2026-08-20) to fail closed and loud
on an unresolvable BG identity rather than silently standing down. For every other seat it was a
no-op. What it enforced, now unenforced:

- **G1** file-write allowlist: the seat could only write to its own `logs/`, `threads/`,
  `deliverables/`, or a tmp/scratchpad path -- specifically excluding its own `prompt.md`, `refs/**`
  and `.claude/**`, so a persuasive Teams message could never rewrite the seat's own instructions.
- **G2** shell-mutation block: no git writes, no `safe-commit`/`safe-apply`/terraform, no S3/DynamoDB/
  Lambda/IAM/Secrets-Manager mutating AWS calls, no shell redirect into repo content outside its own
  folder.
- **G3** Bloomberg download-class MCP calls (`bloomberg_historical_data`, `bloomberg_intraday_bars`)
  denied outright -- his own stated reason was that fresh DAPI delivery consumes a data quota he
  called "serious"; `bloomberg_reference_data` capped at 2 securities per call (single-quote lookup,
  not a bulk pull).
- **G4** identity fence: every `mcp__opal-gateway__*` call (Andrew's own proxy identity) denied for
  this seat -- it may only call `opal-gateway-bbg`; email/site-write tools denied there too, leaving
  Teams replies as its only outbound surface.

None of that is re-implemented elsewhere. If the Bloomberg-quota or identity-crossing concern still
holds, that is a decision for Andrew to make again, not one this removal makes for him.
