# LD-0324 -- Complete the Vident template migration for the PM export CSV (Yang-directed, Andrew-sovereign)

## The trigger (Andrew-direct, forwarding Yang)

Yang emailed Andrew (2026-07-20): *"Can you adjust the output format of 'Portfolio Management' based on the
new template? The columns are different now and it also requires full output of entire portfolio."* Andrew
tasked MSTR to ground the change, plan the fix, and -- on approval + with CTO~A down -- implement it
directly under sovereign authority.

## Grounded finding

The 2026-07-14 Vident "Active Manager Model" migration (b9d61307c, `portfolio-management-v2.2.0`, live)
moved the Vident EXCEL to the new 13-col full-model template in all generator copies, but the
**Trade CSV** the Export-&-Submit flow returns as `tradeCsvUrl` -- the file Yang downloads
(`portal .../ExportModal.tsx:180`) -- was left as the legacy **9-col, trades-only** format
(`generate_trade_csv`). That is exactly Yang's two points: columns differ (9 vs 13) + not the full portfolio.

## The fix (implemented, validated, deploy-follows)

- New `generate_vident_model_csv` -- CSV twin of `generate_vident_excel`: same 13 vendor columns
  (VIDENT_MODEL_HEADERS, tied 13/13 to the vendor file), same full-portfolio `build_model_rows`, same
  CASHTARGET residual + sum-to-1 / partial-model refusal laws.
- Submit flow returns it as `tradeCsvUrl` (no portal change; same field name) + `modelExcelUrl` (the
  compliant `FUND_Model_YYYYMMDD.xlsx`). Legacy `generate_trade_csv` retained but off the live path.
- Downstream-safe: 0 readers of the CSV file in the trade-pipeline; execute regenerates from
  `model_securities`. Vident-facing Excel generator byte-untouched.
- Pre-deploy harness (scratchpad, vs the vendor template file): headers 13/13, CSV rows === Excel rows,
  partial + oversubscribed refusals fire, TargetWeight sums to 1 -- ALL PASS.
- Deploy: source-only zip -> S3 lambda-artifacts (content-sha256) -> `safe-apply` portfolio-management
  (0/1/0 module.excel_generator) -> live CodeSha256 verify -> deploy-completion ledger -> tag
  `portfolio-management-v2.3.0`. The exact 07-14 discipline.
