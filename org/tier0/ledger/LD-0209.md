## Decision
Record, for the Tier-0 / macro-governance trail, the Andrew-direct creation of the
**new macro `DATA`** and its first project **`DATA_PLATFORM`** -- a program to
**assess feasibility for + build a proprietary custodian-data-aggregation platform
replacing Black Diamond + Orion.** Mirrors the NFRA_OPLMCP macro-creation precedent
(LD-0194 class); both CTO + COO flagged it for macro-governance.

## Premise (the strategic thesis)
Opal already aggregates BD/Orion custodian-data + UI-wraps it for 3 partner firms
(49F / Inflection / Cottonwood) into ONE served contract. BD + Orion are, at core,
custodian-data aggregation + a UI wrap -- which Opal substantially already does. So:
**own the aggregation layer rather than rent it.** Grounded on a Phase-0 5-surface
live-repo sweep (Schwab / BD / Orion+Eclipse / SmartX / the 3-firm methodologies).
Likely a SmartX partnership for custodian-aggregation + an Eclipse-class trade layer.

  Audit-first is the de-risking discipline: prove feasibility before committing a build.
