# LD-0547 - The sprint Lambda, built and deliberately not applied

## What the job actually is

Running the sprint by hand end to end (LD-0543) is what made this buildable, because it showed
that only ONE of five steps needs a model:

| step | needs | who |
|---|---|---|
| clone | git + a credential | new |
| two censuses | stdlib + `subprocess(git)` | **the repo's own scripts** |
| **author the JSON** | **judgement** | **gpt-5.6-sol** |
| render | stdlib | **the repo's own script** |
| publish | boto3, verifies by read-back | **the repo's own script** |

The Lambda orchestrates and replaces the human at step 3. It re-implements no rendering and no
publishing — a second implementation of either is the shadow pipeline this estate vetoes.

## The measurement that reversed the design

I told Andrew earlier that a Lambda could not clone this repo, on a 1 GB reading. **That reading
was invalid**: it was taken over `file://`, which silently ignores `--filter` and returns the full
pack. Against GitHub, where the filter applies:

| | |
|---|---|
| unfiltered pack | 2.51 GiB |
| `--filter=blob:none --shallow-since` | **44.4 MiB, ~7 s** |
| censuses in that clone | run unmodified |

⭐ **THE FALSE MEASUREMENT WAS FLAGGED BEFORE IT WAS ACTED ON, WHICH IS THE ONLY REASON IT COST
NOTHING.** A wrong number that reaches a design decision is a design defect.

## Three traps the code is built around, each hit live

1. **The default branch.** `git clone` lands on `origin/main` — 34,000+ commits behind, no `org/`,
   no `daily_reports/`. Hit while measuring this very design: 4,202 files checked out and every
   path resolved to nothing. Checkout is explicit and **proved** by asserting two files exist.
2. **A silently-ignored filter** looks exactly like a clean clone. The handler asserts pack size.
3. **The cloud sees only what is pushed** — 566 of 601 commits on 2026-09-10. Disclosed on the
   page's own `source` line, because a number whose population is unstated is what this estate
   refuses.

## ⛔ Why it is not applied

The repo is private and the credential does not exist. `github-token` returns 401 on probe. The
credential installed today for a different act carries **admin/maintain/push where read-only was
asked** — accepted by Andrew as deliberately temporary and tracked as `NFRA_CLDGRPH` row S123.

**Reusing it here would make a temporary over-grant permanent by reuse**, and a daily scheduled job
is the most permanent consumer there is. The ask is one fine-grained PAT, contents read-only, in
`opal/daily-sprint-github-read`.

## Rollback

Nothing to roll back. No image, no ECR repository, no applied Terraform. Deleting two directories
removes it entirely.
