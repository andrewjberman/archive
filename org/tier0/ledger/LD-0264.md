# LD-0264 -- Execution record: landing the sovereign-authorized `logs/` deprecation cleanup

**What.** Deletes the root `logs/` tree (882 tracked files) and `.smart-lint-backup/` (8) that Andrew
deliberately deprecated, as a series of scoped chunk commits. Authorized twice: direct in-session, and
per-area through COO. Ledgered before it propagates (Art. V) rather than override-bypassed.

**Why chunked.** `.tools/commit-gate.sh:43` and `.tools/comp-surface-check:16` pass **every changed path**
to `python` as argv. 890 paths exceed Windows ARG_MAX; both gates fail with `Argument list too long` and
fail **CLOSED**. That is correct behavior, and `--force` correctly refuses to bypass a gate failure. The
net effect is a real defect: **a large, legitimate, sovereign-authorized commit is currently unlandable.**
Filed to CTO -- batch/xargs the python invocation. Do not "solve" it by widening `--force`.

**Why each chunk carries this ledger.** Constitution Art. V: a strategic MSTR commit touching non-record
paths must include a Decision Ledger entry. Rather than take `MSTR_LEDGER_OVERRIDE` seven times, each chunk
appends its landing line below and commits this file alongside its paths. The gate is satisfied honestly and
the landing log becomes the audit trail.

**Scope guard.** The landing script aborts and unstages if any path outside `logs/` + `.smart-lint-backup/`
enters the index. `infra/aws/` is untouchable here: it is a **rename**, not a deletion, and the owned-paths
hook correctly blocked MSTR (lane `CLOUD_OPS_OR_ETL` = "any AE agent"). Dispatched to `0.5.0_AE_OpalETL`.
