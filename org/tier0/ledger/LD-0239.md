# LD-0239 -- Charter: NFRA_TOOLHEALTH + NFRA_AGENTBUS (the 2 Andrew-discussion items -> CTO briefs)

**What.** Andrew raised two agentOps-maturation items in discussion and directed the briefs to CTO:
1. **NFRA_TOOLHEALTH** -- assess from real agentOps whether comp-tools are used CONSISTENTLY +
   CORRECTLY, as a queryable closed learning loop. A fused per-tool view: USED (compiler-tools-log)
   x RAIL-CONSISTENT (comp-which-rail.log) x EFFECTIVE (COMPPROOF as the recurring probe) ->
   keep/fix/promote/retire, closing the COMPLEARN loop (currently ACCUMULATES-BUT-INERT).
2. **NFRA_AGENTBUS** -- a metered, SCTY-secured SQS bus for cross-Opal-employee agent collaboration
   (parallel fleets). Rides COMPTEAM (onboarding) + SCTY (entitlements). 5 security controls
   (IAM-partition / SCTY-authz-gate / signed-attribution / egress-strip / read-only-default);
   2-layer metering (CloudWatch + app-layer into the same telemetry substrate).

**Deliverables authored:** `docs/briefs/nfra-toolhealth-brief-20260701.md` + `docs/briefs/nfra-agentbus-brief-20260701.md` -> CTO authors the PRD(s).

**Why S2 / not gated:** directive-decomposition redirecting Tier-1, reversible, no S3 act. MSTR
authors + issues to CTO (Art. VI). Leash: AGENTBUS security-gated (no unscoped cross-employee
channel); TOOLHEALTH reuses existing telemetry (no new collection).

**Issued to:** `1.0.0_SA_CTO` (decompose; each may be its own project or a workstream of
COMPLEARN / COMPTEAM; push back on operational grounds).
