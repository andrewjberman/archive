## The general shape, which is the part worth keeping

The row was 18.9% of a 92KB file every agent reads at load because it carried **two different kinds
of thing in one cell**: the AUTHORIZATION (durable law, rarely changes) and the LIVE STATE (armed at
13:00Z, superseded, expired, struck). Authorization belongs in the law file. State does not, and
mixing them is what makes a law file rot.

The state half only became prose here because agent loop-arming leaves **no machine-readable trace**
-- this row says so about itself: *"THIS ROW IS A DURABLE CARRIER BECAUSE THE OBLIGATION LIVED ONLY
IN TWO SESSION LOGS."* It worked. Nothing retired it on the way out, which is the recurring defect:
**a durable carrier written because an obligation lived only in session logs is the same carrier
that keeps the obligation alive after it dies.**
