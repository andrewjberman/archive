# LD-0259 -- /kill maintenance skill (zombie scripts + bloat apps reaper)

**What.** New `/kill` skill + `.tools/kill-maint.ps1` engine. `/kill scripts` reaps orphan
bash/python/py processes not tied to a live claude session and not fabric comms infra; `/kill apps` reaps
bloat GUI apps (Edge, Chrome, Teams, Tailscale, Copilot, ...). `/kill all` does both. DRY-RUN by default;
`go` applies.

**Why the classifier is grounded, not assumed.** The protect-set is built from LIVE process state each run:
the full descendant closure of every claude.exe PLUS a comms-infra cmdline whitelist -- the second is
non-negotiable because the inbox-watch Monitors and agent-pollers run DETACHED from the claude process tree
(verified live), so a pure ancestry check would kill every agent's reachability watcher. A Playwright/
automation-browser guard and a hard-deny system/EDR list round it out.

**Why S1 / safe.** DRY-RUN default, operator-gated kill, and validated against the live fabric: the scripts
dry-run flagged ZERO of 21 currently-legit script processes (the safety proof); the apps dry-run correctly
targeted 16 bloat procs (~2.2GB) while excluding OneDrive (Schwab data-delivery dependency) and WebView2
(embedded system UI) to opt-in flags. Every kill is reversible. Reversible by revert.
