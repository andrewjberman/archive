# LD-0205 — comp-tool auto-log TO_ID concurrency-race fix (Andrew-direct, formal; charter to CTO~B)

## Decision
Charter **1.0.0_SA_CTO~B** to fix the comp-tool auto-log **TO_ID concurrency race**
on the formal track Andrew designated. MSTR root-caused the defect and authored the
implementation brief; CTO~B executes; MSTR RAVC-verifies.

## Root cause (MSTR, ground-truthed)
Every `comp-*` wrapper calls `org/modules/graph/comp_log_auto.py`, which appends
`| date | serial | TO_ID | tool | command | result |` to
`org/compiler-tools-log.md`. `_read_context()` resolves each field as
**env-var → shared `.comp-graph/.agent_context`**. SERIAL is correct per-row because
`ajb.ps1` sets `$OPAL_AGENT_SERIAL` per-process at spawn. **TO_ID has no per-session
source**: `$OPAL_TO_ID` is read but never set anywhere (a TO is assigned *after*
spawn via a COO GO message), so TO_ID falls through to the single global
`.agent_context` file — which every agent overwrites via
`printf "SERIAL=..\nTO_ID=.." > .comp-graph/.agent_context`. Result:
**last-writer-wins across all concurrent agents**; each comp run is tagged with
whatever TO_ID the most recent writer left. Live proof 2026-06-22: DE's `comp-kuzu`
rows → `ADVI_COTETL.AUAFIX-L1` (AE0.7's TO); then CVO/COO/AE0.6 rows →
`ADVI_NNAATTR.TO-1` (DS's TO).

**Severity:** logging-accuracy ONLY — `comp_log_auto.py` silently no-ops on error
and writes only the rolling log + dedup; no gate, artifact, or pipeline depends on
it. The one real cost: it corrupts the **NFRA_COMPRAIL TO-5 coverage-audit** per-TO
attribution.

## Fix (mirrors the proven LD-0070 session-keyed `.serial` mechanism)
This is the identical race LD-0070 already solved for SERIAL via the session-id-keyed
`org/mcp/sessions/<CLAUDE_CODE_SESSION_ID>.serial` file (§7.2). TO_ID just never got
the same treatment. Spec (full detail + sketches + acceptance criteria in the brief):
1. **Read side** (`comp_log_auto.py::_read_context`): insert a session-keyed tier
   between env and the shared file for BOTH fields →
   `env → sessions/<sid>.{serial,to_id} → .comp-graph/.agent_context (legacy fallback)`.
2. **Write side:** `.tools/comp-to <TO_ID>` writes `sessions/$sid.to_id`
   (Git-Bash-3.6.7-safe, ASCII-only).
3. **Discipline:** org/XXX.md Step-1b TO-set + the COO GO-template switch from
   `printf > .agent_context` to `comp-to <TO_ID>` (coordinate with COO).
4. **Cleanup:** `.to_id` reaps with `.serial` in the `sessions/` orphan-cleanup.

Confirmed prerequisites: `CLAUDE_CODE_SESSION_ID` is live in the comp-tool shell
(comp_log_auto inherits it; halt-gate-check.sh already uses it); `<sid>.serial` is
written at org/XXX.md Step 1b; `$OPAL_TO_ID` is grep-confirmed never set.
