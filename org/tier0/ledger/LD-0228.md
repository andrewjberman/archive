# LD-0228 — Commission the NFRA_GLOBGRPH graph-substrate-unification DELTA (IMMEDIATE), issue to CTO -> COO~B

Andrew-direct 2026-06-30. The substrate layer beneath NFRA_COMPUNIFY: get to ONE graph, ONE
marker-published HEAD, where every structure-tool reads the Kuzu graph AT that head.

## Grounded current state (not assumed)

The unified graph **already largely exists** (NFRA_GLOBGRPH PRD §1; Kuzu spans aws 1,451 / ms 5,427 /
portal 11,338; NFRA_TSGRAPH folding components in). The fragmentation is at the **tool layer**:
comp-blast/trace/xref read `.comp-graph/graph.json` (local cache, comp-build-rebuilt); comp-platinum
reads its own cache; comp-graph tracks them as separate vintages. So this is a re-point, not a rebuild.

## The delta (D1-D4)

- **D1** complete the unified graph's coverage of what each structure-tool traverses (function-level +
  symbol + full-stack edges; component-level arriving via TSGRAPH).
- **D2** re-point comp-blast/trace/xref/platinum onto the unified Kuzu graph at the marker head.
- **D3** retire the local trace + platinum caches + comp-build's separate build (re-point THEN retire).
- **D4** one head asserted (COMPDRIFT seam-4 generalized to every structure-tool).
