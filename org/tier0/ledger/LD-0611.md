# LD-0611 -- a RAISE on a key the tree already carries is EXISTING, not a mint

The gate's own docstring says a RAISE is a defect in the rule, not in the diff. When the raising literal is already in the tree, the diff is copying, not minting, and the honest grade says so and points at the migration project that owns the layout. The rule and registry defect itself (the K3 grammar has no slot for a pre-LGIC layout) stays visible in every such line and is LGIC's to close.
