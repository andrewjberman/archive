# LD-0076 — Scribe /mstr-spawn SKILL.md (sibling to /mstr-kill)

## Decision

Per Andrew direct 2026-05-26T~01:35Z + LD-0069 MSTR thin-architecture: scribe `.claude/skills/mstr-spawn/SKILL.md` instituting the spawn-side population primitive via the same structural pattern as LD-0075 `/mstr-kill`. `/mstr-spawn {serial}` is symmetric to `/mstr-kill {serial}` — same invocation shape, opposite population direction.

## Why this exists

Pre-LD-0076, MSTR-side spawning required either:
- Direct invocation of `.tools\spawn-agent.ps1 {serial}` (works, but no structural pre-flight or post-spawn verification — MSTR has to remember the discipline each time).
- Andrew direct authorization for any FORCE_SPAWN overflow (scales poorly; same problem LD-0075 solved for kill).

Andrew's direct comment "also if it isnt obvious, i should be able to spawn the exact same way" identifies the asymmetry: kill got the structural channel (LD-0075); spawn didn't. This LD fills the gap.
