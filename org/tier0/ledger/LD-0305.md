# LD-0305 -- Andrew-launched sessions are presumptively RESERVED

LD-0304 made the fabric able to SEE a session Andrew launched. This entry sets what seeing one
MEANS: refuse the duplicate spawn (already law) and route the fabric's work to a tilde lane by
default -- because Andrew launching a session directly is itself the declaration that he has a task
for it, and "adjacent" is not "directly relevant."

The instance that earned it: 0.8.0_AE_CloudComp, 2026-07-17 -- the refuse fired correctly and the
work was still nearly folded into his session on an adjacency read, sixty seconds after launch.
Detection without a disposition default only moves the failure one step later.
