# LD-0380 -- mstr-ledger-check exempts the audit-archiver's automated snapshots (gate-vs-gate fix)

## The collision (CTO-surfaced 2026-08-06T0055Z; AE-grounded)
mstr-ledger-check CHECK-2 classified the audit-archive-invoker's AUTOMATED tamper-evidence
snapshot commit (2026-08-04T213358Z) as a strategic MSTR commit and REFUSED it for carrying
no Decision Ledger entry. The archiver commits as the RUNNING session's serial (CTO-ruled
Option B, 2026-07-19), so in an MSTR session its author reads as MSTR and org/audit/archive/**
fell to the STRATEGIC catch-all. Result: a governance gate, working as built, punched two
missed checkpoints into the tamper-evidence chain it exists beside. Narrowing datum (CTO):
an explicit CTO commit into the same evidence base passed cleanly -- only the
MSTR-session-authored automated caller tripped.

## Decision

commitment -- same reasoning and authority chain as the session-logs exemption (LD-0258
class): an automated tamper-evidence snapshot is not a decision, carries no LD by design,
and its CONTENT is policed by the invoker's own append-only integrity clause. Narrow by
construction: the pattern is the archiver's entire write surface and nothing else writes there.
