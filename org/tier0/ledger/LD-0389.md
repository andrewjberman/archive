# LD-0389 — Launcher -Model/-Effort passthrough for per-seat model assignment

## Decision
Add optional `-Model` / `-Effort` named parameters to `.tools/spawn-agent.ps1` and
`.tools/ajb.ps1`, threaded to `claude --model` / `claude --effort`, so MSTR can
execute Andrew's per-seat model assignments at spawn time. First use: the CTO/COO
reinstantiation he ordered this session.

## Provenance chain (Art. XIII)
Andrew-direct at the MSTR terminal, 2026-08-11 ~0505Z, VERBATIM: "I need you to
instantiate CTO and COO base with the below. CTO should be Fable model high
effort, coo should be Opus 5 model high effort, here is the handoff info for
their launch: [the MDPF+ADVI canonical-pattern handoff, persisted at
org/tier1_exec/1.0.0_SA_CTO/handoffs/2026-08-11_0503Z.md @1a518b303f]".
The launch chain carried no model/effort surface (grounded: spawn-agent.ps1 param
block, ajb.ps1 $claudeArgs assembly, `claude --help` showing `--model`/`--effort`
live flags), so executing his instruction REQUIRES this mechanism. Chain closes:
his instruction -> the minimal mechanism to perform it -> this commit.

## Why now
The reinstantiation is ordered now; both target sessions are being cycled this
turn. Build Ladder: no existing estate mechanism covers it (rung 2 checked —
launch chain grounded at source), a native platform feature does (rung 4:
claude's own flags) — the change only EXPOSES that native feature through the
two wrapper layers.

## Assumptions
- `claude` validates model/effort vocab (from `--help`; a bad value dies loud in
  the spawned window, observed behavior class, not silently).
- Model alias resolution ('fable'/'opus') is claude's; full names
  (claude-fable-5 / claude-opus-5) are used at the call site to avoid alias drift.

## Alternatives considered
- Hand-rolled Start-Process bypass of spawn-agent.ps1: loses marker + audit +
  caps; rejected (the exact drift the skill warns about).
- Env-var route (ANTHROPIC_MODEL): no grounded effort-level env equivalent, and
  spawn-agent's $inner carries no env hook; rejected as half-grounded.
- Workspace settings.json model key: workspace-wide, cannot differentiate two
  seats in one repo; rejected.

## Rollback plan
`git revert` the single commit; both params are optional and no call site outside
this turn uses them, so revert restores byte-identical legacy behavior.

## Downstream
- Agents affected: any future spawn wanting a model/effort override; none are
  forced (unset = legacy path).
- Paths touched: .tools/spawn-agent.ps1, .tools/ajb.ps1
