# LD-0609 -- the HCL lookup context in the naming gate

The gate's docstring says a firm token is permitted "inside the arguments of a key(), address(), name() or lookup() call (read from the Python syntax tree)". Terraform had only the opal_name-module context, so `lookup(local.performance_scopes, "cottonwood")` -- where `performance_scopes` is built from `infra/logic/registry/scopes.json` -- read as a hand-kept carrier. The permission now follows the data: the key is permitted only when the map it indexes is the registry.
