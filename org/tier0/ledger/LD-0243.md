# LD-0243 -- harden the Project Dashboard generator (decouple from engine internals)

**What.** Follow-up to LD-0242 (Andrew-direct "Do the hardening now"). The dashboard generator had
imported the engine module and called `build_rows()` by its internal signature -- which is exactly
what the 2026-07-06 working-time patch broke silently, stranding the dashboard over the holiday. This
rewires the generator to consume only the STABLE `registry-check.py --json -all` public contract and
inlines the owner-token formatting (a verbatim mirror of the engine's `short_owner`).

**Result.** Zero import-time coupling to engine internals. An internal-signature refactor can no
longer silently break the dashboard; only a deliberate --json schema change would (a loud break).
Output parity verified (56 projects, identical owner/macro/ordering). Regenerated fresh to Desktop.

**Why S1 / not gated.** directive_execution under D-002; reversible internal read-only-tool change.
MSTR owns this tooling (Andrew-direct 2026-07-06). One documented cost: short_owner now lives in two
places (engine + inline mirror), noted in the inline docstring.
