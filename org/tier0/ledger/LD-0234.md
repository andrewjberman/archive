# LD-0234 — Charter: PROVE the NFRA_COMP* program (validation) + a self-extension spike

**What.** Andrew directed a program-proof charter after the NFRA_COMP* assessment +
/draw: spot-check that the graph-substrate program *actually works*, benchmark it
against "every nasty bug we ever had" (starting ADVI_BREAKS) via blind graph-traversal
solving, assess whether COMPROUTE routes well, assess whether COMPLEARN learns
autonomously — and explore whether the loop could **build its own comp-tools** from
logged agent tool-use over time.

**This is the D-001 PHASE-2 meta-test pointed at the program itself.** We built the
shared-cognition substrate; the governing question is whether a real problem walking in
the door actually gets solved, and whether the self-improvement loop actually improves.

**Deliverable authored:**
`docs/briefs/nfra-comp-program-proof-and-self-extension-brief-20260701.md`
(candidate macro `NFRA_COMPPROOF`). Four workstreams, non-redundant, spined on B:
- **A** — seam + process spot-check sweep (breadth; CVO/verify-channel).
- **B** — the incident-regression graph-solvability benchmark (THE SPINE; blind-run per
  incident; SOLVED/PARTIAL/MISS; misses -> gap charters; a STANDING re-runnable suite).
- **C** — COMPROUTE efficacy eval (precision@1/recall on a labeled intent set; CVO
  honesty gate against Goodhart).
- **D** — COMPLEARN autonomy audit (D1: is the loop real or a dead ratchet, grounded on
  live run-artifacts) + the self-extending-toolchain spike (D2: propose its own tools
  from usage; PROPOSED-NOT-DEPLOYED; bounded spike; may warrant CL-fabric re-activation
  = an Andrew sovereign call).

**Why S2 / not gated:** a directive-decomposition that will redirect Tier-1 lanes
(S2 example in the Stakes Matrix), reversible, no S3 act. MSTR authored the charter +
issues to CTO; CTO owns PRD + arch-gates + TO decomposition (Art. VI). The leash bars
auto-deploy of any synthesized tool, preempting the live wave, and inventing incidents.

**Issued to:** `1.0.0_SA_CTO` (decompose; may split a validation macro from a COMPLEARN
self-extension sub; push back on any workstream on operational grounds).
