# LD-0344 — THE LAUNCHER AND THE SPAWN MECHANISM NOW ROOT AT THE REPO, NOT AT ANDREW'S USER PATH.

## What was decided

`.tools/ajb.ps1` (6 operative hardcodes) and `.tools/spawn-agent.ps1` (1) resolved
`C:\Users\AndrewBerman\Desktop\ajb_workspace` as a literal. Both now derive the repo root
from **their own file location** (`<root>/.tools/` -> parent). These are the two files a
second device cannot work without: on a differently-pathed clone, **no agent launches, no
spawns, no kills**.

The root is deliberately **not** `git rev-parse --show-toplevel`: the launcher must work
before/without git, and a CWD-sensitive resolver would re-introduce exactly the ambient-state
coupling being removed.

## The method error this cost, recorded because it nearly hid the whole finding

My first triage reported **10** fragile files and **missed both launchers**. It required an
action keyword (`cd`/`WORKSPACE`/`REPO`) on the line, so it skipped bare assignments like
`$ws = '...'` — the exact form the two most important files use.

> **AN ALLOWLIST OF ACTION WORDS CANNOT ENUMERATE EVERY WAY A VALUE GETS USED.**

Inverted rule: in an executable file a hardcoded absolute path is **OPERATIVE unless the line
is a COMMENT**. That over-reports; it cannot silently miss. 10 -> 43. The under-reporting version
would have shipped a "done" with the launchers still broken.

## And it falsified a premise I had already propagated

I recorded — and put in a session handoff — that `$PSScriptRoot` does **not** resolve inside a
function defined in a **dot-sourced** script, and that a load-time global capture was therefore
*required*. **A probe says otherwise:** it resolves correctly inside such a function and survives
a `Set-Location`.

The global (`$Global:AjbRepoRoot`) is kept, but for an honest reason: **one definition to audit
instead of six**, plus a named override point. Not because the direct form is broken. An
unverified mechanism claim had already reached a durable artifact before measurement caught it —
Rule 22, profile the mechanism before reporting it.
