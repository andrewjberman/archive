## (a) CANONICAL FORM — RATIFIED

| form | path | status |
|---|---|---|
| **CANONICAL** | `inbox/{base}/~{lane}/` | nested |
| **DEAD** | `inbox/{base}~{lane}/` | flat — written by nobody, read by nobody |

Re-derived at source, not accepted on report:

```
server.py:1615        inbox = INBOX_DIR / to_folder.name / f"~{to_suffix}"     (send)
server.py:1745    src_inbox = INBOX_DIR / folder.name    / f"~{caller_suffix}" (check_inbox)
inbox-watch.sh:73-77  BASE_SERIAL="${SERIAL%%~*}" ; SUFFIX="${SERIAL#*~}"      (watcher)
```

All three sides build nested. **A message in a flat directory is delivered to nobody and reported
missing by nothing** — SENT-IS-NOT-READ with the failure moved one layer down, into the filesystem.

## (b) THE XXX.md EDIT — RATIFIED, INCLUDING THAT ITS SMALLNESS IS CORRECT

`9e0bd9b5c1`, **26 insertions / 3 deletions**. Ratified at that size deliberately: XXX.md prose
taxes every agent every session, and CLAUDE.md's own rule is imperative-plus-mechanism in the doc,
reasoning in a ledger. That is why this entry exists and the doc edit stayed small.

### The root cause is the part worth keeping

> **THE STARTUP DOC WAS THE TEACHER.** For a lane serial, `inbox/{serial}/` **is** the flat path.
> XXX.md wrote `inbox/{serial}/` at `:195` and `:246` while writing the correct nested form at
> `:243` and `:417`. An agent substituting its own suffixed serial into the `{serial}` slot
> produced a dead directory **silently, while following the startup protocol correctly.**

**The doc did not merely fail to warn — it generated the defect.** A template variable is an
instruction to substitute, and `{serial}` does not distinguish a base from a lane. This is a
general hazard in every doc that writes `{serial}` into a path: **name the slot's domain, or the
reader will fill it with whatever they are.**

Measured residue: **36 flat dirs, 329 messages, 2026-04-16 .. 2026-06-17.** The last flat write is
**one day before LD-0202** (2026-06-18) landed the architectural fix — the class stopped when the
architecture was fixed, and every survivor is residue. Verified: 36 archived, 329 preserved,
**0 flat dirs remaining** in live `inbox/`, **51 canonical nested dirs untouched.**

### Scope bound — RATIFIED AS STATED, and it is load-bearing

`org/mcp/inbox/` is **gitignored** (0 tracked files). **The directory cleanup is local to one
worktree and propagates to nobody.** Only the XXX.md change is durable. Other worktrees may still
carry flat residue — harmless, since nothing reads it. CVO stated this rather than letting
"cleaned" imply a fabric-wide sweep it is not. **That distinction is ratified explicitly**, because
a future reader finding flat dirs elsewhere must not read it as a regression.

**No gate built — RATIFIED.** The architecture was fixed at LD-0202, nothing has written flat in
six weeks, and the residual risk is agent substitution: a **doc** problem, not a detection problem.
Andrew's standing monitoring moratorium applies and machinery is not warranted. Building a checker
here would monitor a route that is already settled — precisely the anti-pattern the moratorium names.
