## Security protocol (6-phase quarantine pattern)

| Phase | Activity | Risk profile |
|---|---|---|
| **1 — Metadata only** | Fetch README / package metadata / license / basic stats / dependency tree | Zero risk (text-only) |
| **2 — Assess** | /case-find judges: is deeper inspection warranted? | Zero risk (judgment) |
| **3 — Quarantine** | Docker container `--network=none`, no host filesystem mount, read-only ephemeral storage, resource limits; download specific files INTO container | Bounded (network-isolated, no host exposure) |
| **4 — Analyze** | AST parse, dependency walk, pattern shape extraction, suspicious-indicator detection — NEVER execute downloaded code | Bounded (no execution; static analysis only) |
| **5 — Extract** | Abstract Case insight only ("library X uses pattern Y via mechanism Z"); discard raw files | Zero residual (no raw code persists) |
| **6 — Cleanup** | Wipe quarantine container; zero persistent storage of external code on host | Zero residual |

**Core principles:**
- NEVER execute downloaded code (no `pip install`, no `import`, no script run)
- NEVER let downloaded files touch host filesystem (Docker container is the airlock)
- Extract abstract patterns only — Cases queue contains insights, not raw code
- Suspicious-indicator flag at Phase 4 sets CVO judgment gate (discard or extract)
