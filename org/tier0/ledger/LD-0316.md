# LD-0316 -- Create the /exec-sum skill (loopable card-first fabric executive summary)

## Chain

Andrew-direct this session -> MSTR ran the ad-hoc sweep (/stimulus-scan read + /comp-state self-test-PASS
+ /draw) under /loop [30m], delivered a session exec-summary draw -> Andrew: "make it a loopable skill
called /exec-sum," + the one added requirement (a non-technical card at the top, what the fabric is doing
and why, then the /draw feeding back into it) -> MSTR authored .claude/skills/exec-sum/SKILL.md.

## What is created

`.claude/skills/exec-sum/SKILL.md` -- the card-first executive-summary skill. Three-step body: GATHER
(the two grounding instruments), SURFACE (light, coordinator-routed, optional), RENDER (the mandatory
non-technical card, then the grounding /draw). Loop delta via `org/mcp/.exec-sum-state`. Invocation:
bare `/exec-sum` = one-shot; `/loop [interval] /exec-sum` = the recurring exec dashboard;
`/exec-sum --project <CODE>` = scoped.

## The added requirement (Andrew's delta over the raw sweep)

The raw sweep produced a technical draw. Andrew's addition: LEAD with a business-legible card -- WHAT +
WHY, no jargon -- and make the draw *back* it. The skill encodes this as a hard rule: no
serials/commits/jargon in the card (they live in the draw), and every card claim must be traceable to a
real box/edge/pin in the draw (card and draw disagree => one is wrong).

## Related

Skills it composes: `/stimulus-scan` (read half only, not its dispatch mandate), `/comp-state`
(self-test-gated drift), `/draw` (house style), `/loop` (recurrence wrapper). Sibling status lenses it
sits above: `/overview` (prose), `/fabric-check` (agent+project axis). Ledgered per Constitution Art. V
(the mstr-ledger-check gate blocked the skill commit until this LD accompanied it -- a strategic MSTR
commit touching non-record paths is ledgered before it propagates).
