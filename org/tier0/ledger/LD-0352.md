# LD-0352 — Cleanup wave: process-churn and I/O-rate reductions across the fabric's low-level machinery

## Decision

Execute the Andrew-approved cleanup list. Landed in the paired commit:

1. **`org/mcp/server.py`** — `POLL_INTERVAL_S` 2.0 → 10.0. At 2s x 7 sessions this poll was
   ~97% of broker request volume (broker: 64,228 CPU-s over 5 days ≈ 15% of a core). Message
   latency stays bounded by the 5s inbox watcher; channel push unaffected. Deployed-not-running
   on live sessions until they cycle.
2. **`org/mcp/inbox-watch.sh`** — stream-mode `sleep 5` replaced by an in-process `read -t`
   FIFO wait (`_wait5`): the external `sleep` cost one process per 5s per watcher (~121K
   creations/day at 7 watchers). mkfifo-failure falls back to sleep (Rule 16 guarded pattern).
3. **`.tools/agentbus-consumer.py` (new) + `.tools/agentbus-sqs.sh`** — the watch loop's
   per-20s aws-CLI launch (~4,320 full python interpreter starts/day/device) replaced by one
   long-lived boto3 daemon; the wrapper exec()s into it so the MSYS lock pid stays valid, and
   falls back to the aws-CLI loop when python/boto3 is absent. Emit format + emit-THEN-delete
   ordering preserved as contract.
4. **`.tools/hooks/never-rules-gate.sh`** — block-bare-inbox-watch.sh's check folded in as
   GATE 0 (both matched Bash|PowerShell; one spawn instead of two per call). Semantics
   verbatim; one strengthening: the merged gate fails CLOSED on missing jq where the
   standalone passed silently.
5. **`org/mcp/hooks/post-tool-hooks.sh` (new canonical + installed mirror)** — consolidates
   post-tool-telemetry.sh + post-send-commitment.sh + an inlined classify-tool-kind into ONE
   PostToolUse '*' process (was 3 bash spawns per tool call). Two strengthenings: the
   commitment detector's bare-PATH `jq` (a silent no-op in profile-less hook shells --
   measured) now uses the telemetry jq ladder and actually fires; its serial resolution moves
   off the banned shared `.agent_context` onto the session-keyed chain.
6. **`.claude/settings.json`** — PreToolUse 3 → 2 entries, PostToolUse '*' 2 → 1. Old scripts
   left on disk unchanged for in-flight sessions carrying the old config.
7. **Operational (no commit):** /kill storage executed — 769 items, ~1.26 GB reclaimed, 4
   in-use skips. Own poller cycled (new pid at 15s). Own consumer re-armed onto the daemon.
