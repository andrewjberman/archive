# LD-0015 — Amend /govern Step 1(b) commit-activity + STALE rule; charter CTO to codify three accumulated refinements

## Decision
Two-part:

### Part 1 — Procedural amendment (MSTR holds itself starting CY-0013)

Step 1(b) gets two rule refinements:

**(a) Per-agent commit-activity-by-serial check.** For every LIVE agent in
the population scan, compute the elapsed time since their LAST commit by
that serial (`git log --author="<serial>" -1 --pretty=format:"%aI"`).
This is distinct from the prior workspace-wide "any commits since last
cycle window" check, which doesn't surface a specific agent's quiet
duration. The skill body already names "commit-activity-by-serial" in
Step 1(b) but MSTR's execution had been workspace-wide; this amendment
makes per-agent the binding read.

**(b) STALE classification loosened.** The current rule keys STALE on
"open TO." Charters from MSTR + Routing Asks from peers + cross-fabric
acks-pending are not formal TOs but ARE active work waiting on the
agent. The amended rule:

  STALE = registered LIVE AND no recent commit-activity-by-serial AND
          (open TO OR pending charter receipt OR named blocker dependency
           OR routing-ask-from-peer in inbox).

The original "open TO" criterion was too narrow -- it never fired on
2.0.0_SA_COO this cycle (5+ charter/routing-ask threads converged on
her over 3h, no formal TO assigned to her, STALE didn't fire). The
loosened rule catches that case.

### Part 2 — CTO charter to codify three accumulated Step 1(b) refinements

Charter 1.0.0_SA_CTO to fold three procedural-only amendments into
`.claude/skills/govern/SKILL.md` Step 1(b) so they're structural
rather than reliant on MSTR self-discipline:

1. **LD-0013** -- project-status predicate before classifying an
   unaddressed work surface as a spawn candidate (caught by CTO via
   the ADVI_INFGRO rollback).
2. **RV-0001 F-005** -- magnitude-sanity heuristic on numeric
   assertions in broker summaries (caught by Andrew via the
   -$54.8M cap-gains finding).
3. **LD-0015** -- per-agent commit-activity-by-serial check + STALE
   rule loosening (caught by Andrew this cycle via COO 3h-quiet
   question).

Acceptance: a single SKILL.md commit by CTO that folds all three into
the existing Step 1(b) text. CTO RAVC back with the commit hash;
MSTR's CY-0014+ cycles operate under the codified rubric.
