# LD-0225 — Commission NFRA_COMPLEARN (self-learning comp-tool loop over Trino-federated activity), issue to CTO

Andrew-direct 2026-06-30. Commissions **NFRA_COMPLEARN** as a macro-project: reclaim the dormant
COMP_LEARNS runtime (`comp-learns-run` / `comp-learns-status`) as a **fabric-native self-learning loop
over our own tool-use**. The Trino federation gains a third catalog — `tool_activity` — and JOINS
**Behavior x Estate x Change** into one federated activity tracker; a **scheduled, value-anchored
ratchet** learns which comp-tools we need most + when, where coverage gaps are (raw-grep escapes), and
how to optimize/merge/retire the existing set — emitting an **advisory worklist** the CTO ratifies.

## Design summary

- **Behavior catalog** (`tool_activity`) extracted from `compiler-tools-log.md` + `agent_telemetry/*.jsonl`
  + `comp-which-rail.log`, bound as a third Trino catalog beside `iceberg` (Estate) + `code_heat` (Change).
- **The join** (Behavior x Estate x Change) IS the "federated activity tracker between cloud estate /
  git / local directory and daily agent behavior."
- **Reclaimed ratchet**: `comp-learns-run` = tick one iteration (score -> propose toolset mutation ->
  ratchet -> worklist); `comp-learns-status` = the learned dashboard (gap map, optimize candidates,
  champion config).
- **Seed corpus** (Andrew): backfill from 8,600 rolling-log rows (2026-04-09->06-30) + 1,469 session-log
  `## Compiler Tools` sections — dense from iteration 1.
- **Scheduled + alive** (Andrew): EventBridge->Fargate nightly server-side job (NOT an agent self-tick;
  exempt from LD-0175), writing a served worklist; the loop self-sustains.

## Principles (carried to PRD)

VALUE-anchored score (not usage — the COMP_LEARNS benchmark-honesty lesson; the load-bearing Goodhart
risk); ADVISORY-not-auto (worklist, CTO ratifies — NFRA_DEBTSCAN never-auto doctrine); read-only +
vintage-stamped; attribution-correct. Sibling of NFRA_COMPDRIFT on the same Trino substrate (shared
catalog work — sequence once).

## Hand-off

Brief: `docs/briefs/nfra-complearn-brief-20260630.md` (12 sections + 10 asks). Issued to
`1.0.0_SA_CTO` for PRD + arch-gate + TO decomposition + macro-project stand-up. Authority closes at
Andrew, who originated and named the redesign.
