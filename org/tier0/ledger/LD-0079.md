# LD-0079 — Spawn-agent tab title shows agent serial

## Decision

Per Andrew direct 2026-05-26T~02:33Z: enhance `.tools/spawn-agent.ps1` so each spawned PowerShell window's title bar (+ Windows Terminal tab label) shows the agent's serial.

## What changed

Three launcher files modified — one workspace edit per file to set the PowerShell window title to the agent serial at the start of the spawn / launch path.

### `.tools/spawn-agent.ps1` (autonomous spawn entry)

Prepend the title-set to the `$inner` script that the spawned PowerShell runs:

```powershell
# Before
$inner = ". `"$ajb`"; ajb -Headless $Serial$extraStr $marker`: $Serial"

# After
$inner = "`$Host.UI.RawUI.WindowTitle = '$Serial'; . `"$ajb`"; ajb -Headless $Serial$extraStr $marker`: $Serial"
```

### `.tools/ajb.ps1` (manual ws-fabric launcher function)

Add `$Host.UI.RawUI.WindowTitle = $Serial` inside the `ajb` function body, right after the launch banner Write-Host. Covers the path where Andrew (or any operator) types `ajb <Serial>` manually in an existing PowerShell window — title flips at that moment.

### `feature_clb/.tools/clb.ps1` (manual CL-fabric launcher function)

Same pattern, COMP-branch sibling commit. `clb` is the CL fabric's analog to `ajb` (different worktree, baked-in path to feature_clb root). Same title-set inside the `clb` function body.

Mechanism:
- `$Host.UI.RawUI.WindowTitle = '<text>'` is the canonical PowerShell API for setting the host window title.
- Windows Terminal reads the PowerShell-set title and uses it as the tab label by default (`tabTitle` not explicitly overridden in profile settings).
- The leading `$` of `$Host` is backtick-escaped (`` `$Host ``) so the OUTER PowerShell — the one running spawn-agent.ps1 — doesn't try to interpolate `$Host` (which would resolve to its OWN host object as a string). The INNER `$Serial` IS interpolated so the actual serial gets baked into the script string at spawn time.

## Why this is worth a ledger line

Pure operator observability. Pre-LD-0079: every spawned tab reads "Windows PowerShell" or similar generic. Operator (Andrew) sees N identical tabs and has to either click each one or read its content to identify the agent. Post-LD-0079: every tab reads its agent serial — `0.0.0_AB_MSTR`, `1.0.0_SA_CTO`, `0.7.0_AE_CloudOps`, etc.

S0-class (operator UX) but worth recording because (a) it touches the population-primitive surface (spawn-agent.ps1) and (b) MSTR-commit discipline requires ledger-before-propagate.
