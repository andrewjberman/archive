# LD-0097 — Strategic reframe: north-star codification + tri-pronged execution dispatch

## (A) North star — codified

**The entire purpose of the Opal Capital multi-agent fabric is to rapidly expand language- and file-agnostic, systems-wide graphing and traversal capability for AI agents.**

Decompose:
- **rapidly expand** — velocity is a first-order metric; ops friction reduces case velocity which reduces graphing/traversal expansion rate
- **language-agnostic** — Python, JS, Go, Rust, Java, TypeScript, SQL, YAML, etc. — graphing must work regardless of source language
- **file-agnostic** — code, config, data, docs, binaries, schemas — graphing must work regardless of file type
- **systems-wide** — not just one repo; whole-systems graphing spans codebase + infrastructure + documentation + data + external dependencies
- **graphing and traversal** — build the graph (extract nodes + edges from heterogeneous artifacts) + walk the graph (query, trace, compute reachability, find structural patterns)
- **for AI agents** — the consumer is AI agents like the ones running in this fabric; the graph/traversal API is designed for agent-native consumption (structured queries, deterministic outputs, machine-readable)

**Operational expression:** the `comp-*` compiler tools in `.tools/` are the materialized graphing/traversal capability layer. Each compiler tool is a query primitive over some slice of the graph. **Cases are the pipeline that identifies what NEW compiler tools the agents need next** to expand graphing/traversal coverage.

**Evaluation criteria for Cases (CL CTO + CL CVO to translate into operational criteria in their meta-dialogue):**
- Language-coverage delta: does this expand the set of languages the graph spans?
- File-coverage delta: does this expand the set of file types the graph spans?
- System-breadth delta: does this expand the systems (repos, infra layers, external deps) the graph spans?
- Traversal-depth delta: does this enable new query primitives over existing graph coverage?
- Agent-utility: how directly does this serve agent-native consumption (structured query, deterministic output, machine-readable)?
