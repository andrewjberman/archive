## What happened

The passive 11:00Z Bloomberg acceptance (Andrew's own item, kept alive through the MDPF_TRGALN
governance) FAILED: the client-facing benchmarks dashboard was two-seat-confirmed stale (data_as_of
08-12 vs the T-1 target 08-13; today's 07:00 pull fired `rc=1` "could not start blpapi session").

failure mode from the reboot-recovery gap (no reboot fires, so the staged auto-recovery never
triggers).

## The recovery (Andrew Option B, executed by site-Z)

Andrew chose Option B (build+run the automated typer), noting it had been done before and one retry
was fine. The reconcile his "done before" prompted surfaced the exercised 08-11 procedure
(`BLOOMBERG_TERMINAL_SIGNIN_RECOVERY.md` @0d087760ff). MSTR~Z followed it, not an invention:
phased typer (`C:\opal-elev\bbg_signin.ps1`) with foreground-verify, click-not-tab,
screenshot-verify-before-submit (so typing errors cost ZERO Bloomberg attempts), and
verify-before-retry (a 18s-listener-0 lull did NOT trigger a retry once state showed the login
accepted). **Sign-in succeeded first attempt, 1 of 2 budget, no 2FA, DAPI up.** The ad-hoc pull
published 08-13 content-verified (tripwire pass, served == PKL 5/5, `.ST` content check correct).
**Dashboard current at data_as_of 08-13 -- confirmed by BOTH seats' independent live head-object
reads.**

## The fallback directive (build owned by site-Z)

Andrew directed the durable fix: **the terminal upload skill checks blpapi/8194 availability at
start and, if not open, runs the sign-in, then proceeds.** Spec authored (deliverable above),
`# andrew-asked` marker carried. Unsupervised hardening required over today's supervised run:
FIRE-ONCE-THEN-ESCALATE (no retry-loop; account-lock), AGENT-INDEPENDENT, a P0 cheap-remedy gate,
and -- the one new engineering piece -- an AUTOMATED screenshot-verify to replace the human read.

## Residual (named, open)

`0.0.3_BG_BBGTerminal` is still dead. Absent the fallback OR a BG respawn, the failure recurs on the
next Terminal logout. Today closed the DASHBOARD, not the RECURRENCE. Andrew's steer on
build-fallback-now confirms the path; the build lands on site-Z.
