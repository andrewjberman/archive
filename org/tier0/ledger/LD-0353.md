# LD-0353 — Finish-out: dead broker hot-path removed; never-rules test suite un-broken (67/67)

## Decision

Close the two items LD-0352 left flagged, under Andrew's blanket finish-out instruction:

1. **`post-tool-hooks.sh` (canonical + tracked .tools mirror): the async broker hot-path is
   REMOVED, not redesigned** — measurement showed it was dead machinery twice over:
   `.tools/hooks/broker-record-tool-call.py` exists in NO commit in the repo's entire history
   (`git log --all` zero hits) and `broker.py` exposes no matching endpoint. Every tool call in
   every session launched python3 into a file-not-found failure, backgrounded, stderr
   discarded — a per-call interpreter spawn that could never have worked. Nothing consumed the
   path (the stimulus-scan cost signal reads the JSONL files, which remain). Re-exercised
   post-removal: payload → jsonl delta 1.
2. **`test_never_rules_gate.sh`: JQ resolution ladder added.** The suite encoded payloads with
   `${JQ:-jq}` and never resolved JQ; in a profile-less harness shell (no PATH jq — the
   measured norm) the encoder died silently, the hook received empty stdin and exited 0 by
   design, and every DENY arm rendered "PASS (want DENY)": the 32/35 red baseline tracked the
   ENVIRONMENT, not the gate. With the ladder (same as the gate's own): **67 PASS / 0 FAIL** —
   which also upgrades LD-0352's GATE 0 merge verification to full-suite green. Absent jq now
   FAILS LOUD (exit 2) instead of producing meaningless verdicts.
3. Also in this commit: the tracked `.tools/hooks/post-tool-telemetry.sh` mirror of the
   LD-0351 bounded-stdin fix (the .tools gitignore blanket was inverted 07-29, so the mirror
   is a tracked change that LD-0351's commit missed), and the new `.tools/hooks/post-tool-hooks.sh`
   installed copy now tracked.
4. Operational, no commit: own `.unread-deliveries` sentinel cleared (protocol-mandated
   post-acting delete, 132KB of history); 193 legacy-era `tracked_watchers` relics removed
   (stream watchers never write trackers; all were dead-session residue).

## The durable lesson (for the record, not restated in law)

A backgrounded spawn with discarded stderr and a suite with an unresolved encoder are the same
class: **an instrument silenced at its failure point reports its own health as its subject's.**
The hot-path "worked" for weeks because nothing could see it fail; the suite "failed" for
reasons nothing could see. Both were found only by controlling the retrieval.
