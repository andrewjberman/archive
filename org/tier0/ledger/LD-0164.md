# LD-0164 — retire /mstr-review + /spot-check to ad-hoc (lean-loop sweep completion)

## Decision
Andrew sovereign ruling (2026-06-08 MSTR-startup) on SS-0007 open-item #1: **retire both
remaining governance self-tick loops to ad-hoc / invoke-on-demand.**
- **/mstr-review** (MSTR 12h cron) -> ad-hoc. Fires on: Andrew call, MSTR session startup
  (the deterministic startup directive still runs one pass), closeout-class signals
  (session closedown, project close), or on-demand.
- **/spot-check** (CVO 20m cron) -> ad-hoc. CVO alignment-sweep fires on-demand / at
  closeout-class signals rather than on a fixed 20m tick.

This completes the LD-0157 lean-loop sweep (retired /work + /ws-charter 2026-06-05),
removing the last two recurring governance crons. The fabric is now fully event-driven:
persistent Monitor for reachability + COO /drive (running /fabric-check) as the sole
centralized tick driver.

**/watcher (10m) is explicitly EXEMPT** — it is a reachability/registration heartbeat,
not a governance loop, and stays armed every session.

## Why
- SS-0007 #1 flagged this repeatedly as unruled. The 12h/20m governance ticks largely
  produced no-op/clean cycles between real signals; the cost (ticks + context) outweighed
  the marginal coverage now that COO /drive + /fabric-check catch operational blocks and
  closeout-class signals trigger review naturally.
- Consistent with the LD-0157 finding that self-tick loops "wasted ticks"; governance
  review is event-shaped (a window worth reviewing is created by activity, not by the
  clock).

## Actions taken / routed
- **This session (MSTR):** deleted the /mstr-review CronCreate job (`cf4f97db`). Did NOT
  re-arm a /mstr-review cron.
- **Routed to CTO (durable doc-implementation, exec lane per MSTR pure-Tier-0 posture
  LD-0165):** update org/XXX.md startup protocol + the /mstr-review and /spot-check skill
  descriptions to reflect ad-hoc status, and remove the /spot-check auto-arm from the CVO
  startup so a fresh CVO session does not re-arm the 20m cron. CC COO.
- The CVO is not currently live; the doc-implementation lands before CVO bring-up via the
  COO /allocation request Andrew flagged.

## Rollback
Re-arm via `CronCreate /mstr-review 12h` and `CronCreate /spot-check 20m` (CVO) and revert
the doc edits. Fully reversible.
