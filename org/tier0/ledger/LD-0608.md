# LD-0608 -- the drive timer ticks the seat that asked for it, and nobody else

The ajb driver was written for one seat's incident, and every later caller inherited that incident's mail. Any other serial now gets a self-tick only, sent when its own root inbox is empty and the nudge interval has elapsed.

Restart for a running seat: `powershell -NoProfile -ExecutionPolicy Bypass -File $env:USERPROFILE\.codex\skills\drive\scripts\start_drive.ps1 -Workspace <ajb_workspace> -Serial <serial> -IntervalSeconds 600`. With no config.json from the old run, the wrapper stops the old pid and starts the repaired driver.
