# LD-0248 -- land NFRA_CMTQUE TO-6 phase-1 worker-supervisor into server.py

**What.** Wired ~B's commit-worker supervisor into `server.py`: `_ensure_commit_worker()` (mirrors
`_ensure_broker`) is called best-effort right after `_ensure_broker` in `register_agent`, so every session
ensures the commit-worker daemon up (auto-relaunch within one session start; the same reliability the
broker gets). The worker carries max-uptime self-restart + parent-watchdog + results/dlq GC + a pid
singleton. Decided ~B's note-2 UNGATED (warm + live-proven before the flip; one idle singleton daemon).

**Safety.** The register call is try/except-wrapped and the liveness `git rev-parse` is timeout-guarded, so
it can NEVER block registration; a launch miss degrades to the safe-commit D6 fallback-to-mutex and is loud
(WorkerDown alarm). Deferred to session restarts (server.py is long-running). Verified: compile + read-only
liveness + ~B's 4-case temp-repo proof. The flag flip stays a SEPARATE later gate (Andrew+MSTR paired go).

**Why S2 / not gated.** directive_execution under LD-0246 (MSTR owns CMTQUE); a reversible, deferred-
activation, double-guarded change to the live MCP server. Committed with the audited BASE_EXEC override
(org/mcp exec lane; MSTR owns internal-ops).
