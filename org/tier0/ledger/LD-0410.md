# LD-0410 -- /kill reaped the estate's own remote access by name

## The hazard, and it was live rather than hypothetical

`.tools/kill-maint.ps1:108` listed `tailscale|tailscaled|tailscale-ipn` among "bloat GUI apps."
**This laptop is running `tailscaled` and `tailscale-ipn` right now** -- so `/kill apps go` on this
device would have severed the tailnet today, and site Z's the moment it is installed.

Andrew asked for Tailscale remote-in *"so this never happens again."* **A maintenance tool that
reaps the estate's own remote access is exactly that failure.** And per LD-0409, Tailscale is not a
convenience here: it is the instrument that makes the site Z box's only recurring failure class
attributable at all -- the way someone reaches a wedged box to force a dump.

Caught by `0.0.0_AB_MSTR~Z` while prepping the install; independently verified at this seat against
both the engine and `.claude/skills/kill/SKILL.md` (which named it in three separate enumerations).

## Verified -- and the first verification was WRONG

Initial check reported `tailscale=False`, the answer I wanted. **The positive control failed in the
same output**: `chrome` and `Spotify` also read False when they must be True. My extractor had
grabbed the *deny* list, not `$appName`, so the result was meaningless.

Re-run by evaluating the actual expression:

```
^(msedge|chrome|chromium|ms-teams|Teams|mscopilot|mscopilot_proxy|copilot|
  Spotify|Slack|Discord|Zoom|WhatsApp|Skype|GoogleUpdate|SpotifyWebHelper)(\.exe)?$

tailscaled False · tailscale-ipn False · tailscale False
chrome True · Spotify True · Teams True · msedge True
```

**The negatives only mean something because the positives fire.** Recorded because this was my own
fix, checked in the direction I was hoping for -- the exact shape this session has caught eleven
times elsewhere.

## Scope -- what this deliberately does NOT do

- **Nothing installed, no remote access enabled, no firewall or RDP change.** Andrew's outstanding
  Tailscale decisions (install y/n, RDP vs SSH vs both) are untouched.
- One repo file, so it covers **both devices** on pull -- the device-agnostic property LD-0405
  requires of a shared tool.
- The removal is total rather than partial: the service is `Tailscale`/`tailscaled` and the GUI
  sibling is `tailscale-ipn`. **A partial guard would read as protection while leaving a live name
  matched**, which is worse than none.

## Rollback

Re-add the three tokens to `$appName` and the skill enumerations. No state.
