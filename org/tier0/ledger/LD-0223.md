# LD-0223 — Build comp-xray as a CLI (Andrew-direct, MSTR-executed)

Andrew-direct 2026-06-30 ("We need comp-xray built as cli now, that is your task."). Builds the thin
`.tools/comp-xray` CLI over the already-committed NFRA_COMPDIFF engine — the **value-MOTION lens**:
"is this resource's CONTENT genuinely changing, or FROZEN-BUT-FRESH?" (value frozen while the
timestamp keeps advancing — the 3x-2026-06-29 freeze class that mtime/size/existence tools cannot
see).

## What shipped

- **`infra/aws/compdiff/cli.py`** — argparse orchestrator over the engine + axis adapters +
  freeze-monitor. 6 subcommands: `frozen` (headline S3 frozen-but-fresh derivation), `s3` (forensic
  value+freshness timelines), `code` / `config` (git content-fingerprint motion), `schema` (parquet
  footer drift-in-place), `freeze-monitor` (the standing guard, dry-run unless `--publish`).
- **`.tools/comp-xray`** — the thin shim (comp-blast/comp-pipescript pattern) + auto-logging.
- **Catalog registration** — `comp-tools.yaml` block + `graph-call-manifest.yaml` two entries
  (`estate.xray.frozen_but_fresh`, `estate.xray.content_motion_axis`) + `tools_index` line, so
  `comp-which` routes plain-English freeze questions to it (Rule 21).

## Properties

Tri-state exit (0 clean / 1 integrity-break / 2 UNVERIFIABLE); VINTAGE-PRIMARY (grounds the
authoritative S3 object-version / git history, never newest-by-mtime); READ-ONLY; UNVERIFIABLE-is-a-
finding (never a silent clean). Gate-clean (py_compile + ruff py39); engine tests 10/10; all 6
subcommands smoke-verified, including a live `freeze-monitor` read of the inf served artifact (clean —
no false-fire; consistent with the inf issue being a stub-clobber = value-replacement, a distinct
lens from value-freeze).

## Relationship to LD-0221 (NFRA_COMPDRIFT)

comp-xray is the value-MOTION **engine/seam-checker**; comp-drift (LD-0221) is the topology
**orchestrator** that will CALL comp-xray (and the other seam-tools) as engines. Distinct roles —
comp-xray earns its own first-class CLI now because the frozen-but-fresh freeze class is live.
