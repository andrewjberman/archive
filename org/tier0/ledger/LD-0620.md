# LD-0620 -- cleanup-disk.ps1: the fetch runs under cmd and its exit code is read

## Decision
In `Invoke-PoolWorktreeSplit`, `git fetch origin *> $null` becomes `& cmd /c "git fetch origin >nul 2>&1"` followed by
a read of `$LASTEXITCODE`; a non-zero exit prints one WARN line and the pool continues.

## Provenance chain (Art. XIII)
- Found by `0.0.0_AB_MSTR` on a `/cleanup` run at 2026-10-08 ~02:45Z: the engine exited 1 with NativeCommandError at
  line 279 before any pool ran, because three other boxes had pushed and the fetch printed new refs to stderr.
- Ruling: `1.0.0_SA_CTO` msg 106707 item 3 ("infrastructure tooling is the fabric manager's lane ... fix it in your own
  commit: do not send a native command's streams to $null under PowerShell 5.1; read the exit code instead").

## Verification
Parser reports 0 errors; the file holds 0 non-ASCII characters; a dry run of the merged and unmerged worktree pools
exits 0 and prints the split (9 live, 0 fully merged, 0 carrying unlanded commits).

## Rollback
`git revert` of the commit that carries this entry.
