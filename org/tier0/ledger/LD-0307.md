# LD-0307 -- Graph-refresh audit: the local incremental already exists; the fix is scheduling it

Andrew asked for the missing symmetric local process. The audit found it is not missing -- it was
built 2026-07-08 and runs 92x faster than the full reload. What is missing is a SCHEDULE: today the
unavoidable daily full-reload (the nightly whole-table overwrite tripping the large-delta gate)
ambushes whichever agent queries first each morning. Andrew's design -- MSTR pays the full at
startup, workers ride incremental -- schedules that cost onto a deterministic, non-blocking moment.
The one thing his design needs to actually deliver its guarantee is sec 5.1: a worker's -inc must
serve labeled-stale rather than fall back to full. Held for his paired review with AGENTBUS.
