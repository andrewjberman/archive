ledger entry. MSTR structurally cannot override its own gate (correct by design), so the fix is at the hook.

through; nothing that previously passed can now fail. CHECK-1 (universal Tier-0 record integrity) and the
strategic-ledger requirement for genuine non-record commits are untouched. Same class as the existing
2026-06-29 gate-hygiene allowlist entry. Andrew sovereign-authorized ("fix this now"). Reversible by revert;
installed hook reads .tools live so the fix is immediately effective.
