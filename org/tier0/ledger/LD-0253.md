# LD-0253 -- spawn hardening: disable user-blocking tools on -Headless spawns (closes the frozen-fork stall)

**What.** On `-Headless` (autonomous) spawns, `ajb.ps1` now passes `--disallowedTools AskUserQuestion
EnterPlanMode ExitPlanMode` -- hard-removing the user-CHOICE tools so an unattended agent can never strand
on an unanswerable fork (0.6.1's 6h dark-stall root cause). It routes decisions to its exec via the broker
(remote-answerable) instead. `--skip-permissions` covered permission prompts but NOT these.

**CTO's two refinements (load-bearing).** Exempt by **interactivity** (`if $Headless`), not MSTR-identity
(a headless MSTR must not strand either). Disable the plan-mode **pair** (Enter+Exit), not Exit alone --
removing Exit-without-Enter creates a stuck-in-plan-mode strand (a *worse* failure). "A fix must not create
a new failure mode."

**Verified before land:** flag-composition test (claude ran clean with both flags, exit 0) + ajb.ps1
parse-check (0 syntax errors). Reversible; interactive sessions unchanged. 0.6.1 already retired.
