# LD-0462 -- CLAUDE.md becomes the LAW INDEX; the teaching text becomes the ANNEX

## The problem, in Andrew's words

707 lines, "a lot of it is indulgent," recommended length ~80 -- "agents arent reading most of
it or any of it." A law file nobody absorbs protects nothing: it is the
protection-that-exists-only-as-a-description class applied to the law itself.

## The measurement that shaped the cut

- 42 of the rules ALREADY ended in pointers to fuller homes (docs/doctrine, memory, skills,
  ledgers) -- the depth largely existed elsewhere; the file was carrying teaching text on top.
- The file's own editing law states the format: **"A rule = imperative (<=2 lines) + mechanism +
  pointer"** -- and almost every rule violated it. The slim is the file obeying itself.
- The estate had already proven the pattern once: the 2026-08-25 move of rules 4-18 to
  `/cloud-ops`, numbers preserved, citations still resolving.

## What was done

1. `docs/doctrine/CLAUDE_ANNEX.md` -- the full pre-slim text, MECHANICAL copy, byte-verified
   (`diff` clean against the source). Nothing was transcribed, nothing deleted.
2. `CLAUDE.md` rewritten as the index: sections and stable rule numbers unchanged (20/20
   grep-verified), one mechanism kernel per rule, existing pointers kept, compressed rules
   pointing at `Annex §N` for their history.
3. Three-surface delivery: commit + same-turn broadcast + push state in the broadcast.

## The floor, and the option below it

262 lines is the floor REACHABLE WITHOUT breaking "never cut a MECHANISM." The path to ~80-120
is structural, not editorial: move sections 6/7 (lane + data law) to a DS-loading skill, the Git
section to the shims/wrappers' own docs, and the comp-tools table into `comp-which --help` --
each the /cloud-ops pattern again, each needing Andrew's word since it changes WHO sees the law
by default. Staged as a follow-on question, not executed.

## Part 2 (same act, Andrew's editorial direction ~22:0xZ)

His words: sections 7 and 8 and the Compiler Tools table leave the index entirely; the Code
Quality build ladder moves INTO section 4 near the top ("that part of checking for things that
already exist and not doing duplicative work is important enough it should be closer to the
top"). Executed: 262 -> 215 lines. Rules 15/17/17a/17b/19/23/25/26 keep their stable numbers
with the annex as their citable home, declared in the preamble so the citation contract holds.
