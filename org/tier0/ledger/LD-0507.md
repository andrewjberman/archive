# LD-0507 — four values retired, and the two placements he did not name are marked as mine

## Decision

`commit_kind`: **14 values -> 10 + a named residual.**

```
  RETIRED        PATHS WENT TO                                        WHOSE CALL
  ARCHITECTURE   PLANNING  (docs/architecture/, *_PRD.md)             his, verbatim
  DECOMP         PLANNING  (workflows/)                               MINE
  OPS            GOVERNANCE (org/critical_paths/)                     MINE
  OPERATOR       nothing -- the value is gone                         his, verbatim
```

⭐ **He named ARCHITECTURE's destination and did not name the other two.** Retiring a value does
not say where its paths go, and a silent re-home is a taxonomy edit wearing someone else's
authority. Both are recorded in the README table with `whose call` beside them **so either can be
reversed without disturbing his**:

- **DECOMP -> PLANNING.** Decomposition is work done BEFORE execution, which is exactly what
  PLANNING means once design and spec fold into it.
- **OPS -> GOVERNANCE.** A deploy ledger is a register of controlled changes — the same family as
  `org/tier0/ledger`, which was already GOVERNANCE.

## ⭐ Retiring OPERATOR strengthened a postulate rather than weakening the enum

OPERATOR was author-derived and was therefore the enum's **only declared grain exception** under
Rule 24 (ii) — LD-0506 kept it and named the exception as the discharge. With it retired, **every
value is an activity class without exception** and `classify()` no longer reads the author at all
(the parameter is retained only for call-site stability and is explicitly discarded).

A human commit is now typed by what it touched, like any other. Exercised: Andrew + `CLAUDE.md`
-> GOVERNANCE; Andrew + an unmatched path -> UNATTRIBUTED, **not** a preserved OPERATOR escape
hatch.

## ⛔ The README's own prose was carrying the retired claim, and that is the carrier readers hit

The four-postulate record was rewritten in LD-0506, but the **content-laws paragraph above it**
still read *"`by_kind` = the AUTHOR SEAT CLASS (a declared proxy for kind of work — 'Coordination
208' means 208 commits were authored by COO/MSTR seats)"*, and the layout block still called
`commit_census.py` *"(measured)"*. **Two carriers agreeing and a third contradicting them is the
failure mode this estate keeps paying for** — the record is not corrected until its last surviving
copy is. All three now agree, and the retired sentence is QUOTED in place with its retraction,
because a reader who learned the old meaning needs to be told it changed rather than quietly
served a new one under the same legend.
