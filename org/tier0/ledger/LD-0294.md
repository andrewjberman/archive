## Decision

1. **send_message authenticates its sender** (server.py, G-A extension `_sender_conflict`):
   - Registered caller + mismatched `from_agent` = **FORGED → hard refuse**, audited `SEND_FORGED_REFUSED`, nothing written. `identity_override` escapes it AND stamps the true author into the delivered artifact (`**Sender-override:**` line) — an authorized relay is never a silent impersonation.
   - Unregistered caller = **UNVERIFIED → deliver, stamped** (`**Sender-unverified:**` line) + audited — never block the recovery path.
   - `from_agent=""` auto-fills the registered serial (removes the error instead of catching it).
2. **set_summary is self-scoped** — a summary is a self-claim; foreign write refused + audited (`SUMMARY_FOREIGN_*`), override audited.
3. **check_inbox(mark_read=True) is self-scoped** — foreign DRAIN refused + audited (`INBOX_DRAIN_*`); foreign READ stays legal (inspection). Override for dead-agent cleanup, audited.
4. **register_agent/heartbeat hard refusals now write `CROSS_REFUSED` audit rows** (deduped) — previously only overrides were audited; the guard's most decisive action was its least measurable.
5. **inbox-watch.sh stream mode self-exits on parent death** (the orphan-thief ROOT fix): `kill -0` on the Monitor eval wrapper each poll cycle; parent gone → audited `WATCHER-SELF-EXIT` + exit 0. Fail-OPEN on PPID<=1 / `INBOX_WATCH_NO_PARENT_CHECK=1` (never suicide on a probe that cannot see its subject).
6. **Instruments must show their observations**: kill-orphans prints a start banner before any fallible work; the register-hook failure row carries `bash=` + `out_bytes=` (the one `ORPHAN-CLEANUP-FAILED` row on record read `rc=1 out=` — undiagnosable; root cause recorded as UNDETERMINED, now self-diagnosing on recurrence).
7. **Guard version bumped GA-2 → GA-3**; the `IDENTITY_GUARD_ACTIVE guard=GA-3` rows are the activation denominator (per-session activation — landed is not reachable-from-the-runner; live sessions run GA-2 until their MCP servers restart).
