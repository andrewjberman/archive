# LD-0647 -- Portal pre-push: a missing gate script fails closed on DEV and PROD

## Decision
In `.tools/portal-hooks/pre-push`, when the VALGATE D-1 gate script or the DEV payload gate script is not found:
- a push to `refs/heads/DEV` or `refs/heads/PROD` exits 1 with one ERROR line naming the script and `bash .tools/portal-hooks/install.sh`;
- a push to any other ref (a `cand/<box>/<slug>` branch, a worker branch) prints the same WARN as before and continues.
The payload limb is checked only for DEV, as before; D-1 runs on every ref, as before.

## Provenance chain (Art. XIII)
CTO ruling `org/tier1_exec/1.0.0_SA_CTO/deliverables/CTO_RULING_20261014_013xZ_PORTAL_PREPUSH_MISSING_GATE_FAILS_CLOSED_ON_TRUNKS.md`
@38d124d991 (msg 109024; it answers CTO~DELL2's request, bus cf368eb7, and my question) -> "0.0.0_AB_MSTR carries this in the same hook
it patched (the hook's lane is ANY), under an LD" -> this edit. LD-0646 (6d0381ff98) is the path-resolution change it follows.

## Why now
dell1 and dell2 showed the silent-absence class: a hook that read as installed and gated nothing. With LD-0646 the gates are found on
a gitlink layout; this closes the case where they are still not found.

## Assumptions
- The escape on a trunk is the CTO-ruled audited `# never-override: <reason>` path. The hook has no reader for that comment (it sees
  only stdin ref lines), so this change adds no new in-hook escape; a trunk push with a gate missing is refused until the install is repaired.
  Flagged to the CTO in the report on this change.
- `remote_ref` is exactly `refs/heads/DEV` or `refs/heads/PROD` for a trunk push, as the existing DEV limb already assumes.

## Alternatives considered
- Fail closed on every ref: the CTO ruled it out (stops feature work for an install defect).
- Add an environment-variable escape in the hook: an unruled bypass; not added.

## Rollback plan
`git revert` of the commit that carries this entry restores the WARN-and-continue behaviour byte for byte; re-run
`bash .tools/portal-hooks/install.sh` on each box to refresh the installed copy.
