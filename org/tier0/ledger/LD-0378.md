# LD-0378 -- The N-copies-of-one-universe divergence class (INF rep-scope specimen)

## The finding (AE~A, verified @8e69ae4cb; scope ruling Andrew-direct ~1958Z @93c898445)
A firm-scope constant (`INFLECTION_REP_IDS`) is duplicated across ~10 sites in the inf tree
and the copies ALREADY DISAGREED: the pull layer carried [3,6,7,8,10,11,12] and fetched
rep 10; every filter site carried {3,6,11,12} and discarded him. Both halves "worked," so
the divergence was invisible until an advisor reassignment made it load-bearing. Measured
cost: a 5-day INF gold-chain outage (2026-08-01..08-05) plus five live funded accounts
silently mis-bucketed to a firm advisor_key on a portal-served surface.

## The class
A live instance of CTO's 2026-08-04 "a predicate is not a roster" ruling, one turn worse:
not merely a hand-drawn roster, but N INDEPENDENT COPIES of one, free to drift apart.
**The estate has no instrument pointed at "are our N copies of this universe the same."**
Presence-style instruments cannot see it: every copy individually looks healthy; only the
CROSS-COPY comparison carries the signal. Same family as the day's delivery-is-not-measured
specimens -- the load-bearing property (copy agreement) was not a property any instrument
looked at.

## Decision
1. The class is NAMED on the tier-0 record (this file) so remediation cites a class, not an
   incident.
2. GATE CANDIDATE routed to CTO: a cross-copy agreement check for duplicated universe
   constants -- EITHER consolidate to one derived predicate per CTO's 08-04 ruling (the
   real fix, and what the INF remediation should do), OR where duplication is temporarily
   unavoidable, a comparison instrument that fails on divergence. Consolidation is the
   preferred form; the instrument is the interim.
3. Ownership of the live fix unchanged and NOT re-routed by this LD: DS lands the code
   (Rule 13), AE~A holds re-run/deploy; acceptance = chain-complete AND five 'unknown'
   rows gone AND no excusal -- not chain-green.
