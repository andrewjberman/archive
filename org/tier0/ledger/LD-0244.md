# LD-0244 -- new skill /activity-check (commit-activity axis + top-4 pie charts)

**What.** Andrew-direct: a new `/activity-check` skill in the /registry-check + /to-check house style
-- the 5 most recent commits from each active agent, plus a summary section aggregating where recent
activity is directed via three top-4+"Other" pie charts (Macros / Projects / Agents).

**Shape.** engine `.tools/activity-check.py` (text + `--json`) + render
`.claude/skills/activity-check/render_activity_dashboard.py` (HTML: per-agent recent-commit cards + the
three pies) + `SKILL.md` linking both. Active agent = a fabric serial that committed in the `--days`
window (default 7), pods collapsed to the role-agent. Macro/Project charts count project-directed
commits; the Agent chart counts all commits (raw volume). Render consumes the engine's `--json` public
contract (hardened per LD-0243), not internals.

**Why S1 / not gated.** directive_execution under D-002 (governance-tooling extension); new read-only
lens, reversible by revert, writes one local HTML file on demand. MSTR owns this tooling class
(Andrew-direct 2026-07-06). `.tools/` is gitignored (terraform-binary intent) so the engine is
force-added via safe-commit's `git add -f`, matching the grandfathered registry-check.py / to-check.py.
