# LD-0510 — the ruling reaches the page, and the enum had four carriers

## Decision

`by_project.streams` (`[id, title, count]`, string id) + `timeline.stream`, wired through
`render_daily_report.validate()`, `_shared_viz.js` and **both** templates. Verified end to end:
the project legend now reads `… Platform Ops 61 · **Planning 9 · Audit 71** · Unattributed 26`.

Streams are a separate key rather than extra `counts` rows because a counts row is
`[int, title, count]` through the validator, the schema and both templates, which colour projects
by `PCOL[n % 12]` — indexed by directive NUMBER. **A string id there would break the chart
silently at render time.**

## ⛔ THE FIND: LANDING LD-0506/0507 WITHOUT THIS WOULD HAVE BROKEN TOMORROW'S RENDER

The `commit_kind` enum had **four carriers**, and after the rewrite **only one was correct**:

```
  1. commit_census.KINDS          AUTHORITATIVE, current
  2. render_daily_report.KINDS    STALE -- a literal restating the same enum
  3. _shared_viz.js KIND map      STALE -- colour lookup, keyed by the same values
  4. schema by_kind enum          STALE -- and enforced by nobody (see below)
```

Carrier 2 would have **rejected the census's own output**: `unknown commit_kind: 'AUDIT'`, the
validator refusing the data its sibling script produces. Carrier 3 is worse than an error —
`KIND[k]` on a missing key is `undefined`, the template reads `[0]` off it, **and the page still
builds and displays the word.** ⭐ **That is one of the routes by which the `undefined` Andrew
reported reaches a served page**, and no check that reads the JSON alone can see it, because the
JSON is correct: **the drift is BETWEEN carriers, so only a check that reads BOTH can catch it.**

**Fixes, structural not cosmetic:**
- Carrier 2 is **deleted** — `render_daily_report.py` now imports `KINDS` from `commit_census`.
- Carrier 3 cannot cross a language boundary, so `check_kind_palette()` reads `_shared_viz.js` as
  TEXT, extracts the `KIND`/`STREAM` keys, and **refuses to render** when the data carries a value
  with no colour. If it cannot find the map it says so rather than passing — *"palette unchecked,
  which is NOT the same as a palette that passed."*

## ⛔ THE SCHEMA IS NOT A GATE, AND THE RENDERER'S DOCSTRING CLAIMED IT WAS

`render_daily_report.py` opened with *"Checks it against
daily_reports/schema/DAILY_REPORT.schema.json"*. **Measured: `jsonschema` appears ZERO times across
all 28 files in `daily_reports/`; the module imports only argparse/datetime/json/os/sys; and the
schema path appears exactly once in the file — in that docstring, never in code.**

So `additionalProperties: false`, every enum and every `maxLength` in that file are enforced by
nobody. Everything actually checked is hand-rolled in `validate()`.

>> **THE CONSEQUENCE FOR THE NEXT PIECE OF WORK, recorded because it would have been wasted
effort:** the open `undefined` gap — `"params": {"type": "object"}` with no per-type requirements —
**cannot be closed by editing the schema.** A constraint added there is a no-op. It must go in
`validate()`. <<

The docstring now says all of this in place, rather than being quietly corrected.

## Controls — three falsifiers, all fired, plus a positive control

A guard that has never failed is a promise, not a control.

```
  kind with no colour entry        -> FAILS x2: "unknown commit_kind: 'WIDGETRY'" AND
                                      "has no colour in _shared_viz.js KIND -- the legend
                                      would render `undefined` instead of failing"
  stream in the bar, absent from   -> FAILS: "the bar would show a segment the area chart
  timeline.stream                     cannot draw"
  streams dropped from the sum     -> FAILS x3: the two-cuts-of-one-population invariant
                                      plus both per-series sums
  POSITIVE CONTROL: the good file  -> renders, 444,303 B
```

Rendered page checked in a headless browser: **0 occurrences of `undefined` or `NaN` in the
rendered text**, 11 kind segments, 8 project-axis segments (5 directives + 2 streams + residual),
`scrollWidth == viewport`.

⚠ **Streams were added to the sum invariant deliberately.** Omitting them would have let a JSON
carrying streams pass while the two cuts no longer described one population — **the invariant
defeated by adding a bucket it did not know about**, which is the failure mode of every
allow-list that is not updated with its domain.

## Rollback

Revert this commit. `by_project.streams` and `timeline.stream` are optional in the reader
(`bp.streams||[]`), so a JSON without them renders exactly as before.
