# LD-0147 — /govern not auto-armed at startup (Andrew-discretion); default cadence 20m -> 1h

## Decision
Two changes to the `/govern` loop, both Andrew-direct:
1. **Not auto-armed at MSTR startup.** MSTR no longer arms a `/govern` cron at session
   load. Whether to run `/govern` — and at what cadence — is Andrew's discretion. He
   invokes it when he wants the tactical sweep.
2. **Default cadence 20m -> 1h.** When `/govern` is loaded as a loop, the default
   interval is 1 hour (was 20 minutes).

`/mstr-review 12h` remains the only standing MSTR cron armed at startup.

## Provenance chain (Art. XIII)
Andrew direct ("no govern loop needed, dont load govern at load, that is up to my
discretion if we load it or not, furthermore, the loop default should be 1 hr") ->
D-001 (operational governance of the MSTR loop architecture) -> edit /govern SKILL.md
(default 1h + Andrew-discretion-only) + org/XXX.md §F MSTR row (drop the /govern
auto-arm) + this LD superseding the LD-0124 startup-arm clause + cancel the live
/govern 20m cron (d442c553). Chain closed.

## Why now
Three consecutive `/govern` cycles this session were quiet (Andrew actively present,
no Andrew-silent actionable items) — the auto-armed 20m loop earned little and Andrew
prefers to pace it himself. He reset both the trigger (discretion, not auto-load) and
the cadence (1h, not 20m).

## Relationship to prior LDs
- **Supersedes LD-0124** (the clause "govern should be in launch/startup for MSTR ...
  as a loop on 20m"). LD-0124's reasoning was sound at the time; Andrew has since
  decided he wants /govern on-demand, not standing.
- **LD-0090 unchanged.** The ALWAYS-PROCEED three-clause discipline still governs how
  /govern behaves WHEN loaded. This LD changes only when/whether it is armed and its
  default cadence — not its proceed-on-rec semantics.
- **LD-0069** (the original /govern-as-supervision retire) remains historically correct
  and orthogonal.

## Rollback plan
Re-add `CronCreate /govern <interval>` to the org/XXX.md MSTR startup row and restore
the SKILL.md "every 20 minutes (default)" + the auto-arm "When to invoke" bullet.
Fully reversible at the doc layer; no code.
