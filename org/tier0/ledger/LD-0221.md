# LD-0221 — Commission NFRA_COMPDRIFT (first-class estate-wide drift compiler), issue to CTO

Andrew-direct 2026-06-29. Commissions **NFRA_COMPDRIFT** as a macro-project: a first-class drift
compiler (`comp-drift`) that **owns the canonical propagation topology** —
`local -> git -> cloud -> nessie -> kuzu -> iceberg -> trino -> served` — and enforces the invariant
that **each hop is in parity with the stage before it**, instead of the status quo where drift
detection is scattered as side-functions across ~10 tools with no owner of the chain.

**The core moves (full scope in `docs/briefs/nfra-compdrift-brief-20260629.md`):**
- **Topology-owning, not aggregating.** Existing seam-checkers (`comp-heat drift`,
  `comp-pipescript deployed`, `comp-lambdamap parity`, `comp-iam reconcile`, `comp-registry sync`,
  `comp-transform schema-check`, `comp-freshness`, `comp-incrparity`, `comp-parity`) become **engines
  comp-drift calls**; the new first-class artifact is the **topology manifest + coverage ledger**
  (`org/modules/graph/drift-topology.yaml`) — deliverable #1, which surfaces the **uncovered seams**
  (seam-5 Iceberg, seam-6 Trino) that are invisible today.
- **Trino = fan-in federation node** (N inbound catalog seams; git-code-heat is a live-read special
  case) whose silent binding-layer drift is `schema-check generalized per catalog`. Its drift-signal
  is to be an **AC on the live heat-federation build** (design-in, the one-time window), not a retrofit.
- **Carried principles:** normalized drift-record + tri-state exit (0 clean / 1 break / 2 UNVERIFIABLE),
  NEVER silently MATCH an unread seam (the false-clean class killed in the 2026-06-29 to-check parser,
  generalized), per-hop verdicts stay DISTINCT (no collapsing into one "DRIFT").

**Lane:** MSTR scope (this + the brief) -> 1.0.0_SA_CTO PRD + arch-gate (topology schema; engine-vs-
reimplement boundary; drift-record + CI contract; Trino fan-in model; the heat-federation cross-
dependency mechanism) + macro-project stand-up + TO decomposition -> 0.7.0_AE build -> 3.0.0_SA_CVO
verify. The Trino cross-dependency must be coordinated with the NFRA_GLOBGRPH/heat-federation owners
NOW, before their federated surface materializes.
