## The finding that justifies the pre-flight discipline

The pre-existing `github-token` secret returns **HTTP 401 — expired or revoked.** MSTR's first design had
the box self-register at boot by reading it. **That would have built the instance successfully and then
failed to register, presenting as a healthy box that simply never claims a job** — the day's governing
class (*the thing you believe happened, didn't*) in an eighth costume.

It was found only by **exercising the mint path** rather than assuming a named secret was good. Andrew's
constraint (*"we don't use any GitHub PATs"*) then made the design strictly better: **no credential is
stored anywhere**; registration tokens are single-use, ~1h, minted at point of use.

**Disclosed against MSTR:** while pre-flighting, MSTR printed that PAT into the session transcript via
`--output text`. An error. Mitigated by the token already being invalid, but recorded here because **a
disclosure that lives only in a transcript is not a record.** Deleting the stale secret is an open item at
