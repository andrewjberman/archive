# LD-0232 — NFRA_COMPROUTE: elevate the router to a first-class project (the generalizable systems alpha)

Andrew-direct 2026-07-01: "what is the true router, what NFRA project is that" + "let's get serious,
where is the generalizable systems alpha here -- we should have an NFRA project devoted to the more
comprehensive approach we discussed an hour ago."

## The gap he named

The routing DECISION has no home. comp-which is the SURFACE; the decision is scattered (curated RULES +
fuzzy backstop + a §4a tenant in COMPLEARN). The DE's curated fixes are O(1) one-offs. The alpha is the
ENGINE -- and it needs a first-class owner.

## The elevation

Stand up **NFRA_COMPROUTE** = the fabric's intent->capability ROUTER, a self-improving, surface-aware
POSTERIOR DECISION ENGINE (`prior x likelihood x learned-affinity + margin gate`). Re-home the LD-0231
§4a posterior spec here (preserved); narrow COMPLEARN to the training-signal provider. Four-peer
architecture, disjoint verbs, no meta-drift:

- **COMPRAIL / TOOLHUD** -- FIRES the router (when-to-route + HUD + gate).
- **COMPROUTE** (new) -- DECIDES (the posterior; the true router).
- **COMPUNIFY** -- MAPS (the one-home capability catalog = the prior source).
- **COMPLEARN** -- TRAINS (tool_activity + the affinity signal).

## Why a project, not a fold (the alpha)

Routing = the fabric's attention-allocation problem, the highest-frequency cognitive junction (HUD
~639x/14d). The engine is (1) fabric-wide compounding leverage, (2) generalizable beyond comp-tools to
skills/MCP/docs and ultimately WHICH-AGENT a TO routes to (learned dispatch), (3) a self-improving
flywheel off tool_activity, (4) context-as-prior. A curated rule is O(1) and decays; the engine is
O(compounding). Built capability-map-agnostic from Stage 1 so Stages 2-3 (cross-capability, agent-lane
routing) are new data, not a re-architecture.

## MSTR self-correction

LD-0231's "a delta to COMPLEARN, not a new project" optimized for fewer-projects over correct-
decomposition. The router is a distinct capability (a peer to the map + the loop), and a dedicated home
is the LESS-drift choice. Owned + corrected here.

## Scope boundary

Commission (scoping) only -- router/substrate unchanged by this commit. CTO authors the PRD, re-homes
§4a, and owns the engine + generalization-interface design.
