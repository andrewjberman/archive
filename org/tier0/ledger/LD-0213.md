# LD-0213 -- new fabric skills /goal-set + /verify (Andrew-direct; ouroboros-pattern clean-room)

## Decision
Ship two new `.claude/skills/` skills, Andrew-direct:
- **`/goal-set`** -- lean goal-driver: ask <=3 quick questions (skippable) -> set the goal
  -> arm a self-driving `/loop [interval] <Drive the goal to completion; /verify at
  completion and adjust if necessary>`. The loop drives, `/verify` gates, it adjusts to SOUND.
- **`/verify`** -- one portable completeness check on three axes (MECHANICAL / DECLARATIVE /
  SEMANTIC), grounded vs the real artifact, verifier!=do-er; condenses the
  `/molecule`+`/seams`+`/verify-channel` family into a single lean gate.

## Provenance
Pattern inspired by the ouroboros spec-first-then-verify loop, **vetted read-only under
SCTY** ([[LD-0211]]) -- pattern adopted **clean-room**, external code NOT run (the
canonical SCTY "vet -> pattern-yes / code-no" outcome). Both skills also ship in the
`agent_org_blueprint` kit (portable, colleague-facing).

## Scope / non-regression
The rich verify family (`/molecule` node, `/seams` edge, `/verify-channel` delivery+closeout)
**remains canonical** for deep verification; `/verify` is the quick gate `/goal-set` uses,
not a replacement. No new authority, no external code, no critical surface touched
(surface-check PASS), no new cron.

## Rollback
Delete the two skill dirs (`.claude/skills/goal-set`, `.claude/skills/verify`) + retire this
LD. Fully reversible; changes no operational state beyond skill availability.
