# LD-0286 -- THE STARTUP DOC HAD DRIFTED INTO AN INCIDENT ARCHIVE

## The scope rule, restated

**`org/XXX.md` holds only what is true for EVERY agent, EVERY session, INDEFINITELY** — identity
resolution, RAVC, the authority hierarchy, MCP startup, the Andrew-direct convention.

It had accreted: a time-bounded operational hold on one pipeline (INF), a dead second fabric
(`feature_clb`), a retired loop model, a log nobody has written since March, and roughly 200 lines of
incident forensics. **Every agent that spawned read all of it, before reaching Step 2 on line 300.**

> **Andrew, correctly, deleted the INF block himself** — it was project-specific, time-bounded, and
> irrelevant to a DT or RD agent spawning in. **It existed only because PROSE WAS THE ONLY CONTROL**
> during the window before the chokepoint was applied and exercised (LD-0284). *Once a machine enforced
> it, the paragraph should have been deleted the same hour. It wasn't — because I was maintaining it,
> and I kept AMENDING it (four times in one day, as its own content kept being falsified) instead of
> asking whether it should exist at all.*
> ## **THE ANSWER TO "EVERY AGENT MUST KNOW THIS" IS A GATE, NOT A PARAGRAPH IN THE STARTUP DOC.**

## Group 1 — ACTIVELY WRONG (not merely verbose)

These are the day's signature failure: **a comment that was true when written, that the ground moved
under, still arguing persuasively in the codebase's own voice.**

| Section | What it taught | Why it is false |
|---|---|---|
| Step 1b ORPHAN block (29 lines) | *"Nothing reaps them"*; *"the reaper is gated on the dead agent's own return"* | **The hook was FIXED today** (`920a7bb77`). It reaps, and it audits — the first hook-driven `KILL-ORPHAN` lines in 693 audit entries. |
| Task Orders | The **"MCP suffix-strip semantic"** — a GO addressed to the wrong serial silently fails to push | **LD-0202** established this was a `server.py` query/write-layer bug and **FIXED** it. The broker DB is suffix-clean. |
| `/loop` — "Universal Watchdog Mode" | A 60s/270s self-scheduling wake loop that **"never auto-exits"** | **The exact model LD-0157 / LD-0164 / LD-0175 RETIRED.** It contradicted Section F *on the same page* ("ZERO crons at launch"). |

- **ka_testing `[*runtime]`**, **legacy exit-on-delivery watcher** — both self-described as retired.

## Group 3 — SLIMMED (the rule stays; the forensics move to their pointer)

The pattern throughout was a **one-line rule carrying a twenty-line incident story.** The stories are
valuable — several are the only reason we did not repeat the incident — **but they belong at the
pointer, not in the doc every agent reads before it has done anything.**

**Nothing is deleted from the estate.** The orphan/reachability forensics already live verbatim in
`.claude/skills/watcher/SKILL.md`; the `.agent_context` false-witness incident lives in the LD ledger
and RV-0046. XXX.md keeps the *rule* and cites them.

## Verified live — deliberately untouched

**The archetype tag** (440 session logs use it), **the Core Documents XMLs** (31 in use), the comp-tool
role minimums, RAVC, Closure Discipline, and the identity-resolution precedence (a real gate, from the
2026-07-12 misadoption incident). *A census that cannot show what it KEPT is not a census.*

## Amendment — the scope rule Andrew tightened mid-execution

**Andrew-direct, verbatim:** *"i dont think we need historical documentation in this doc, better to keep
it purpose-driven, active."*

**That is stricter than the rule I was applying, and it is the correct one.** I had been *preserving* the
history in place while trimming around it — including writing NEW historical parentheticals ("this rule
once cited…", "the former Universal Watchdog Mode…") in the very commit meant to clean it up.

> ## **A STARTUP DOC IS READ BY SOMEONE WHO HAS DONE NOTHING YET. IT MUST TELL THEM WHAT TO *DO*.**
> **The scar is not the rule. The rule is the rule.** The scar belongs in the ledger, where someone
> deciding whether to *weaken* the rule will find it — not in front of someone trying to *start*.

The rule is now stated in the file's own header: **XXX.md holds operating rules, not history; incident
history and rationale live in `org/tier0/ledger/` and the linked docs.**

**One class of thing was NOT cut, deliberately:** where a rule is unobeyable without its mechanism (an
orphan watcher *manufactures* a REACHABLE verdict; `.agent_context` is a shared last-writer-wins file),
the **mechanism** stays — because a bare prohibition loses to the agent's own instruments. **The
mechanism is not history. The incident is.**
