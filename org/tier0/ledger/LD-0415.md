**This is the load-bearing half of P0.** Each of these was measured coupled to the running service.

each is commented AT ITS SITE, not only here.

| Pinned name | Why it cannot move yet |
|---|---|
| `EC2_MANIFEST` service key `m365-mcp-gateway` | It is both the `safe-ec2-deploy.sh` CLI argument and the `tag:Name` fallback resolver in `deploy-to-ec2.sh`. |

| `var.name` default | One variable drives nearly every resource name in the module. See the correction below. |

## Three corrections to the LD-0414 plan, each measured

1. **The EC2 retag is NOT a zero-impact P0 item.** LD-0414 placed "retag the instance
   (`Name`->`opal-gateway`, `System`->`OpalGateway`)" in P0 as mechanical. Both tags are
   Terraform-owned -- `Name` from `aws_instance.gw.tags`, `System` from the provider `default_tags`
   block. Doing it by CLI manufactures drift AND breaks `deploy-to-ec2.sh`'s instance resolver.
   **Moved to P2, where it rides the Terraform change.**

2. **The real rename lever is ONE Terraform variable, and it is a destroy/recreate cascade.** The
   plan described building `opal-*` twins by hand (P1). In fact `var.name` in
   `terraform/opal-gateway/main.tf` drives `${var.name}-sg`, `-role`, `-profile`, the ALB, the TG,
   and the instance Name tag. Flipping that default is far less hand-work than the plan assumed --
   but because AWS names are immutable it is a **destroy/recreate**, including the ALB, whose
   replacement changes its DNS name.

3. **The client-facing endpoint is SAFE, and DNS is not as clean as the plan said.** Verified at the
   live primitive: `mcp.opalinvest.dev.` is an A/ALIAS whose target is
   `m365-mcp-gateway-1854602644.us-east-1.elb.amazonaws.com.` -- so the brief's "DNS is CLEAN" is
   true of the record NAME and false of its TARGET. The consequence is favourable: `dns.tf` manages
   that alias and points it at `aws_lb.gw`, so an ALB replacement **auto-repoints the alias**.
   `https://mcp.opalinvest.dev/mcp/` is stable across the whole cutover and **no agent MCP
   re-registration is needed.** The exposure is the flip window, not the address.
