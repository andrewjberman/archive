# LD-0064 — Retire /cvo-loop skill (both CVOs)

## Decision

Per Andrew direct order 2026-05-25T~20:40Z: retire /cvo-loop skill from both ws CVO (3.0.0_SA_CVO) and CL CVO (3.1.0_SA_CVO).

## Rationale

**Structural redundancy with /verify-channel under LD-0062 + Andrew's trigger refinement.**

/cvo-loop's body (per skill description + `org/tier1_exec/3.0.0_SA_CVO/VALIDATION_LOOP.md` charter):
- 30m scheduled validation loop
- Workspace-wide commit delta sweep
- Deep verdicts on closure-gates / wave-gates / PRD-ships **via verify-channel discipline**
- Verifier-not-fixer

This is exactly the cadence-driven comprehensive verification pattern Andrew's /verify-channel refinement explicitly designed AWAY from (verbatim 2026-05-25T~20:19Z):

> "verify-channel should be exhaustive; spot-check is more than enough for most activity, it really should only be verify-channel at project/channel/pipeline/definitive closeout."

A 30m scheduled comprehensive-deep-verdicts loop directly contradicts the "only at definitive closeout" discipline. /cvo-loop pre-dates LD-0062 (chartered Andrew directive 2026-05-22) — it was the right model for that earlier architecture; under the new one it's redundant with the canonical CVO skill family.

## Post-retirement CVO skill family (canonical)

| Skill | Trigger | Scope | Authority |
|---|---|---|---|
| `/spot-check` | 20m cron | fast alignment + drift + substance-meta-check | fix-authorized for alignment-metadata |
| `/verify-channel` | event-triggered (composite closeout-threshold) + 2h lightweight scan | comprehensive project-scope at closeout; surface-level mode for artifact-grain | verifier-not-fixer |

Two canonical CVO skills, clear cadence/depth separation, no redundancy.
