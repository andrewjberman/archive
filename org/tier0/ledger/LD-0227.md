# LD-0227 — Establish the NFRA_COMP* program + commission NFRA_COMPUNIFY (the top-down coverage map), issue to CTO

Andrew-direct 2026-06-30. Binds three comp-tool meta-projects into ONE program and commissions the
foundational one.

## The program (one noun, two verbs)

- **NFRA_COMPUNIFY** = the **MAP** (static taxonomy + non-redundant provenance) — NEW, this LD.
- **NFRA_COMPDRIFT** = a verb on **resource-STATE** parity across seams (LD-0221).
- **NFRA_COMPLEARN** = a verb on **tool-USE** optimization across surfaces (LD-0225).

COMPUNIFY is the skeleton both loops reference; all three share one Trino substrate, authored once.
Program frame: `docs/briefs/nfra-comp-program-architecture-20260630.md`.

## COMPUNIFY in one paragraph

A top-down, non-redundant, provenance-clear coverage taxonomy over **5 surfaces** (local / git /
aws-cloud / ms-cloud / trino-federation): narrow apex -> high-level tool per surface -> seam tools ->
drill-down detail tools. **Acceptance criterion (Andrew-direct):** every tool has ONE home =
(surface|seam) x granularity x concern; declared concern-difference is the only license for two tools
to touch the same resource; silent overlap = merge/disambiguate. Deliverable = a machine-readable
coverage/provenance ledger that supersedes the flat `tools_index`, + a gap census (ms-cloud/local/
trino-front, seam-5/6) + a redundancy census (IAM x3, parity x3, freshness x4). Brief:
`docs/briefs/nfra-compunify-brief-20260630.md`.

## Sequencing

COMPUNIFY's schema skeleton FIRST (the shared schema; else the loops drift); COMPDRIFT + COMPLEARN
build in parallel against the stable apex. The COMPDRIFT/COMPLEARN briefs get re-pointed at the
COMPUNIFY schema once shaped (held until then to avoid re-work).

## Hand-off

Both briefs issued to `1.0.0_SA_CTO` for PRD + arch-gate + TO decomposition + macro stand-up. Authority
closes at Andrew, who originated and named COMPUNIFY + the program.
