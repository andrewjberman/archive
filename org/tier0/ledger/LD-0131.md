# LD-0131 — Tilde-lane ferry misrouting degrades HALTGT signal (CTO+MSTR co-owned fix)

## §1 — The issue (empirical, 2026-05-28)

COO's LD-0099 filesystem-direct ferries to `~B` tilde lanes scatter EXTRA copies into UNRELATED base inboxes (`0.1.0_DS_MarketIntelligence` 2×, `0.7.0_AE_CloudOps` 1× this session). Each scattered copy trips the base agent's pre-push HALTGT (`halt-gate-check.sh`) on traffic not addressed to it, forcing a HALT_ACK override to clear (3× this session). Canonical copies DO reach the intended `~B` lane (RD~B ACK'd), so delivery works — the bug is the scatter.

**Why it matters:** reflexive HALT_ACK to clear misrouted noise erodes the HALTGT signal — an agent habituated to ack-ing away "not mine" ferry copies could ack-away a REAL `[STOP]`. That is deploy-safety degradation, not mere annoyance. No active `[STOP]` has been lost yet (moderate-urgency).
