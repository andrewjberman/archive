# LD-0610 -- a packaged file name is the citation of the file it packages

`judge()` already returns None for a value that resolves to a tracked path (R-11). A packaging manifest repeats that path under a second spelling, the in-zip name, and lists those names as members. The second spelling now inherits the first's status, and only when the first resolves.
