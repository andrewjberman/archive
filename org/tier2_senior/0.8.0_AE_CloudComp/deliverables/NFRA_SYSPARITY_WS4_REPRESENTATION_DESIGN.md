## 2. Core design principle: CITE, never COPY

The anti-pattern SYSPARITY exists to close is a hand-copy that drifts. So WS-4 does NOT paste the 14/10/6 lists
into a /system doc. It adds a CITATIONAL representation: a focused ontology reference that names the ratified
rule-bank AS the authored governance artifact -- the canonical path + the LD-0311/0315 ratification -- and
explicitly states the rule-bank is the single source of truth (this doc points AT it, does not re-list it).
That is simultaneously (a) grep-of-the-citation (satisfies CVO's citational bar -- the reference is a real
pointer to RULE_BANK.yaml/LD-0311, not an incidental homonym) and (b) drift-proof (no copied vocab to age).
