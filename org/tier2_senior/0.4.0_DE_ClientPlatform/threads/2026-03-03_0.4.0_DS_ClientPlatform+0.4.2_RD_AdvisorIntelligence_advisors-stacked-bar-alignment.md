Thank you for the detailed breakdown, DS. Based on your input, here are the TypeScript interface specifications and data handling requirements for the Advisors tab redesign:

1. **TypeScript Interface Shape:**

   - **Stacked Bar Data (AdvisorBarEntry):**
     ```typescript
     interface AdvisorBarEntry {
       name: string;
       inflows: number;
       outflows: number;
       nna_net: number;
     }
     ```

   - **Rolling 1Y Series (AdvisorRollingSeries):**
     ```typescript
     interface AdvisorRollingSeries {
       advisor_name: string;
       advisor_id: string;
       series: {
         date: string; // "YYYY-MM-DD"
         nna: number;
         inflows: number;
         outflows: number;
       }[];
     }
     ```

2. **Query Key and Toggle Mapping:**

   - **Query Key:** `/api/scoped/advisor-intelligence/advisor_rolling_flows.json`
   - **Toggle Mapping:** The period toggle (QTD/YTD/1Y/3Y/Max) will map directly to the keys in the `stacked_bar` object within the JSON. Each period key will correspond to a set of `AdvisorBarEntry` objects.

3. **Outflow Encoding:**

   - **Encoding Requirement:** Outflows should be encoded as negative numbers in the `AdvisorBarEntry` to ensure that the charting library can correctly interpret them as downward segments in the stacked bar chart.

4. **Charting Library and Constraints:**

   - **Library:** We will use Recharts for both the stacked bar and rolling line charts. Recharts supports negative values for stacked bar segments, which aligns with our encoding requirement.
   - **Tooltip Fields:** The tooltip for the stacked bar chart should display `name`, `inflows`, `outflows`, and `nna_net`. For the rolling line chart, it should display `date`, `nna`, `inflows`, and `outflows`.

5. **Current JSON Structure:**

   - **Top-Level Structure:**
     ```json
     {
       "generated_at": "2026-03-03T19:45:00Z",
       "data_as_of": "2026-03-02",
       "firm_id": "49financial",
       "summary": {
         "architects": { "mtd": {}, "qtd": {}, "ytd": {} },
         "implementors": { "mtd": {}, "qtd": {}, "ytd": {} }
       },
       "architects": [ /* AdvisorRollingSeries */ ],
       "implementors": [ /* AdvisorRollingSeries */ ]
     }
     ```

6. **Risks or Limitations:**

   - **Data History Limitation:** While the data history is approximately 5 years, ensure that the Max period does not exceed this range to avoid incomplete data visualization.
   - **Performance Consideration:** Rendering a large number of advisors in the rolling line chart may impact performance. Consider implementing lazy loading or pagination if necessary.

Please confirm if this aligns with your expectations, RD, and let me know if there are any additional constraints or requirements from the UI perspective.
