<background>
critical-surfaces.yaml defines the monitoring protocol (org/modules/graph/critical-surfaces.yaml §71-86):
  - commit_gate: comp-surface-check tool (sibling of comp-manifest-check); SEV1=block-with-ack, SEV2=warn
  - scheduled_scan: nightly (derive -> Nessie -> kuzu_stitch_load); checks §9 break-scans + baseline diff; alarm via SNS/EventBridge
  - baseline: comp-xref --save per surface x firm (DE generating in D8-DE parallel TO)

AC8 (PRD §10.5): commit-time change-gate flags a synthetic SEV1 surface touch (block-with-ack); scheduled scan emits SEV-routed alarm on a synthetic break/baseline-drift; all firm-specific.

<scope>
Part A — comp-surface-check (commit-time gate):
- New tool `.tools/comp-surface-check` (sibling of comp-manifest-check)
- Input: changed files (from `git diff --name-only HEAD` or passed as args)
- Mechanism: maps each changed file -> affected critical-surface subgraph nodes (via comp-diff + carve-root from critical-surfaces.yaml); emits per-surface verdict (SEV1 block-with-ack / SEV2 warn / NONE)
- Output: "CRITICAL: change touches model_portfolios.benchmark backend for firm 49financial (SEV1) -- confirm + justify" when SEV1 triggered
- Integration: pre-commit hook (comp-manifest-check pattern) or advisory pre-apply check
- Best-effort: if comp-diff fails or carve can't resolve, emit ADVISORY (never hard-block on tooling failure)

Part B — scheduled scan alarm wiring:
- The nightly derive->Nessie->kuzu_stitch_load already runs; extend (or add a post-load step) to run the D7 break-scans against each carved critical subgraph
- diff result vs D8-findings.md baseline (generated by D8-DE; coordinate on baseline artifact path)
- alarm routing: reuse deployed firm_isolation_guard_triggered SNS/EventBridge pattern for SEV1 (page); SEV2 = digest
- alarm fires on: new SEV1 break (finding not in baseline) OR baseline-drift (node/edge removed from SEV1 subgraph)
- clear: re-sign the baseline (comp-xref --save with new --reason) to acknowledge expected changes

Sequencing: Part A (comp-surface-check) can proceed independently. Part B needs D8-DE baselines + D8-findings.md to exist first (coordinate with DE on baseline artifact format/path). CTO registry review of carve-roots also in-flight; hold Part B alarm wiring until CTO ACK (don't alarm on unreviewed carve).

Acceptance (AC8 AE portion):
- comp-surface-check fires on synthetic SEV1 file-touch (block-with-ack emitted); SEV2 warns; unrelated change passes clean
- Scheduled alarm wires against D8-findings.md baseline; synthetic break (added dangling_fetch finding) triggers SEV1 alarm
- RAVC2 to COO on Part A completion; note Part B sequence dependency
</scope>
