### Recommended Priority Fixes (Top 3 by Impact)

1. **#26 + #5 -- PageThemeContext is a complete no-op.** 16+ pages pay the cost of a React context provider wrapper that writes values no component ever reads. Either wire `usePageTheme()` into components that should consume the accent color (e.g., for dynamic theming of headers, borders, active states) or remove the entire context system and the 16+ `<PageThemeProvider>` wrappers. QUICK WIN to remove; MODERATE effort to properly wire.

2. **#17 -- getSentimentColor 4-way duplication.** Three independently maintained local copies of the same sentiment-to-color mapping function, plus the canonical shared version that nobody imports. A color threshold change in one file will silently drift from the others. Fix: delete local copies, import from `colorTokens.ts`. QUICK WIN.

3. **#23 + #24 -- Orphaned pages and tabs.** MarketUpdate is a fully-built page that is completely unreachable (redirected to CausalityEngine). Five PortfolioManagement tabs are leftovers from a deprecated workflow. Combined, this is hundreds of lines of dead code that will accumulate staleness and confuse future developers. QUICK WIN to delete.
